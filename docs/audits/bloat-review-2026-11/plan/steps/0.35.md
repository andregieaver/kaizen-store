# Step 0.35: Point Tailwind at code only

Phase 0 (Before the doors open) of `docs/audits/bloat-review-2026-11.md`. Effort S. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model alone. Six named lines of CSS, a self-contained describe added to a test file step 0.34 leaves, and an exact before/after class comparison that names any class lost; nothing touches money, data or sign-in. *(Rating checked twice, 12 November.)*

**Goal:** Tailwind reads only code for the stylesheet: not tests, not the interface texts, not the schema folder and not the migrations' SQL; the built stylesheet loses the ten classes only tests name and nothing else, and a scan test holds the lines.

**Why:** Today Tailwind reads 5,931 files (22.5 MB a build), 37% of its candidates come from tests, message files, src/db and SQL, and ten classes that only a test names are in the production stylesheet. After: about 3,984 files, 1,739 of today's 1,749 classes, and a word in a test can no longer change the stylesheet.

**Closes:** [AS-7](../../findings/files/AS-7.md), [CS-6](../../findings/styles/CS-6.md). Each finding's file has the evidence.

## Do not

- Do not remove `source(none)` from the tailwindcss import or `@source not "../data"`: without them Tailwind reads every tracked file and the Vercel build runs out of memory (D378).
- Do not add a safelist or `@source inline(...)` to keep the ten classes: nothing draws them.
- Do not edit tests to stop naming those classes.
- Do not exclude src/lib as a whole or any folder not named here: only the six new lines.
- Do not split the stylesheet or add a second CSS entry: that is step 2.11.
- Do not raise the Vercel machine or its memory settings: nothing here needs a paid plan.

## Stop and report if

- comm -23 lists a class that is not one of the ten: a real class was named only in a file now left out. Report the class and the file that names it (rg the name over src and supabase); do not push.
- comm -13 lists anything (a class appeared).
- The build fails or Tailwind rejects a `@source not` line with a glob: report the error text and the Tailwind version (package.json).
- An e2e test fails on a missing style.
- A local build cannot be made twice in the sandbox (memory): report it; the comparison is the step's proof and may not be skipped.
- src/lib/stylesheet-sources.scan.test.ts does not exist (step 0.34 is not in main yet): stop; do not create the file yourself.
