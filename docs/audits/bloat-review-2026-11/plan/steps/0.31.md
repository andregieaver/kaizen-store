# Step 0.31: Run prunes daily, not every five minutes or every minute

Phase 0 (Before the doors open) of `docs/audits/bloat-review-2026-11.md`. Effort S. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model alone. Every move is a named line from one file to another, nothing touches money or a migration, and the scan test and the existing route tests catch a wrong move.

**Goal:** Old rows are pruned once a day (or once an hour for the two logs kept 24 hours), not every five minutes and not every minute: seven prunes run in the daily route, two hourly, and the delivery and workflow-run prunes leave the every-minute runners.

**Why:** Nine of the dispatcher's 78 jobs only delete old rows and run 288 times a day (23 statements a run), and four deletes run every minute inside the delivery and workflow runners (about 5,760 a day). After: the dispatcher has 69 jobs, the seven prunes run once a day, two once an hour, and the four deletes once a day.

**Closes:** [FT-3](../../findings/features/FT-3.md). Each finding's file has the evidence.
