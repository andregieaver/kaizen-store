## The work

### Commit 1 of 3: A script wraps long lines of Markdown and proves no word changed

- **create** `scripts/lib/wrap-docs.mjs`: Plain Node ESM, node built-ins only, no reading of process.cwd() (the caller passes paths), in the style of scripts/lib/ratchet-count.mjs. Export four things. (1) LIMIT = 500 and WIDTH = 130. (2) wrapText(text): returns the text with every over-long prose line wrapped. Split the text on '\n' and walk the lines. A line that matches /^\s*(```|~~~)/ toggles a flag inFence and is kept. A line is kept as it is when inFence is true, when its length is at most LIMIT, when its trimmed start begins with '|' (a table row) or when it begins with '#' (a heading). Any other line is wrapped so: find the continuation indent: if the line matches /^(\s*)([-*+]|\d+[.)])(\s+)/ the indent is as many spaces as the whole match is long (so the text lines up under the bullet's words); else if the line starts with '>' the indent is '' (a blockquote's later lines may leave the '>' out; Markdown joins them); else the indent is the line's own leading whitespace. Then cut the line into pieces: the first piece keeps the line's own start; each next piece is the indent plus words. Break only at a single space character, and only where the count of backtick characters before that space in the whole original line is even (never inside a code span). Take the last such space at or before column WIDTH of the piece being built; if there is none, take the first such space after it (a piece may then be longer than WIDTH). Before accepting a break, look at the text that would start the next piece: if it matches /^([-*+>#|=]|\d+[.)]\s|```|~~~)/ move the break back to the previous allowed space, and repeat until it does not match (if no earlier space is allowed, use the next allowed space after instead). Remove the one space at the break. Trailing whitespace of the original line stays on the last piece. Join everything with '\n'. (3) sameWords(before, after): true when before.replace(/\s+/g, ' ') === after.replace(/\s+/g, ' '). (4) longLines(text): { prose, table } = the number of lines over LIMIT that are not table rows and not inside a fence, and the number that are table rows (trimmed start begins with '|').
- **create** `scripts/wrap-docs.mjs`: The command. Root is path.join(import.meta.dirname, '..'), as scripts/ratchet.mjs does. It builds the list of files with fs.readdirSync (recursive walk, no rg, no git): every file ending in .md under docs, minus this exported constant SKIP, matched on the repo-relative path with forward slashes: the file docs/decisions.md (its rows are split in step 2.40); the file docs/shopify-parity.md (generated by pnpm parity:write); every path that starts with docs/wave-10-notes/ or docs/ab-testing-spike/; every file that matches /^docs\/audits\/psi-2026-[0-9-]+\.md$/; every path that has a folder named evidence under docs/audits (/^docs\/audits\/(.+\/)?evidence\//). CLAUDE.md, AGENTS.md and README.md at the root are not in the list. Two modes. 'node scripts/wrap-docs.mjs': for each file read it, wrap it with wrapText, and if sameWords(before, after) is false print the file's name and exit 1 without writing ANY file (collect all results first, write only when every file passed); then write the changed files; then print three lines: 'docs/rules: <n> prose lines over 500 before, <n> after', 'other docs: <n> before, <n> after in <files> files', and 'table rows over 500 (left as they are): <n> in <files> files'. 'node scripts/wrap-docs.mjs --check': write nothing; print the same three lines with only the current counts and exit 1 when any prose line over 500 is left. Count docs/rules as the files whose path starts with docs/rules/ and 'other docs' as the rest of the list.
- **create** `src/lib/wrap-docs.test.ts`: A Vitest unit test that imports wrapText, sameWords and longLines from '../../scripts/lib/wrap-docs.mjs' (as src/server/ratchet.scan.test.ts imports ratchet-count.mjs). Cases, each on a string built in the test with 'word '.repeat(n): (a) a 900-character bullet '- ...' comes back as several lines, the first starting '- ', the others starting with two spaces, none over 130 characters, and sameWords is true; (b) a numbered item '12. ...' gets a four-space continuation indent; (c) a 900-character line that starts with '|' is returned unchanged; (d) a 900-character line between two ``` lines is returned unchanged; (e) a line with a 300-character code span (one backtick, 300 characters with spaces in them, one backtick) is never broken between the two backticks; (f) a bullet whose text holds ' - ' and ' 1. ' and ' # ' in the middle never yields a continuation line whose trimmed start is '- ', '1. ' or '# ' (build the string so one of them falls at column 130); (g) a 400-character line is returned unchanged; (h) a line starting with '> ' is wrapped, its later lines do not start with '>', and sameWords is true; (i) longLines counts one prose and one table line in a three-line sample; (j) wrapText(wrapText(x)) equals wrapText(x).
