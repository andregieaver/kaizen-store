## The work

### Commit 1 of 2: scripts/decisions.mjs: split the decisions into a file each and write the index, with a proof that no word changed

- **create** `scripts/decisions.mjs`: A node script with no dependencies, shaped like scripts/parity.mjs, with four commands. Shared parsing: read docs/decisions.md; a decision row is a line matching /^\| (D\d+) \|/. Split a row into cells at ' | ' boundaries that are outside code spans (text between backticks) and are not an escaped pipe ('\|'); drop the leading and trailing '|'. Cell 1 is the id. Rows have 2 to 6 cells today (169 with 2, 379 with 4, 16 others where a pipe sits inside code); the code-span rule makes the odd ones 2 or 4: if a row still does not give 2 or 4 cells, exit 1 naming the id. In a 4-cell row the cells are id, decision, date, consequence; in a 2-cell row id and text. Every date cell of a 4-cell row today is YYYY-MM-DD (387 of 387): if a 4-cell row's third cell, trimmed, does not match /^\d{4}-\d{2}-\d{2}$/, exit 1 naming the id (a row split at the wrong pipe would otherwise pass the proof, which ignores pipes). 'split': for each row write docs/decisions/D{n}.md: line 1 '# D{n}: {title}', where title is the row's bold lead (the first **...** of the second cell, without the asterisks) cut at its first '(' , '.' or ':' and trimmed; a blank line; then the second cell's full text as a paragraph; for a 4-cell row a blank line, 'Date: {third cell}', a blank line, and the fourth cell as a paragraph. Wrap each paragraph so no line is over 500 characters: break after a sentence end ('. ' followed by a capital letter or a backtick) at or before column 500, else at the last space before column 500; never break inside a code span; if a single code span is longer than 500 characters exit 1 naming the id. The proof, run inside 'split' for every file: take the file's text without line 1 and without the one 'Date: ' label the script itself wrote (only that one, at the start of its own line; a 'Date: ' inside a decision's text stays), remove every whitespace character and every '|'; take the row's line without its id cell, remove every whitespace character and every '|'; the two strings must be equal, else exit 1 naming the id and the first differing position. 'write': replace everything between the markers '<!-- decisions:index -->' and '<!-- /decisions:index -->' in docs/decisions.md with the index: the header '| # | Decision | Date | Text |' and its rule line, then one row per file in docs/decisions sorted by number: '| D{n} | **{title}** | {date or empty} | [text](decisions/D{n}.md) |', the title cut with an ellipsis so the whole row is at most 190 characters. 'check': exit 1 unless the index in docs/decisions.md equals what 'write' would produce, every file is named D{n}.md with line 1 starting '# D{n}:', no id appears twice, no line in docs/decisions.md or docs/decisions/*.md is over 500 characters, no index row is over 200 characters, and no file under docs/decisions or docs/decisions.md is over 200,000 bytes. 'new "Title sentence."': take the next free number (highest file number plus 1), write docs/decisions/D{n}.md with line 1, an empty line and 'Date: {today}', run 'write', and print the id. Print one summary line per command (rows read, files written, longest line). Export the functions (split, write, check, newDecision(title, date) and indexRow(n, title, date), the one builder of an index row) and run a command only when the file is the one node was started with (`import.meta.url === pathToFileURL(process.argv[1]).href`), so tests and scripts/lib/claim-decision.mjs can import it.
- **create** `src/lib/decisions-script.test.ts`: Step 0.41 tests its script from src/lib (src/lib/claim-decision.test.ts imports '../../scripts/lib/claim-decision.mjs'), so this test is a Vitest file in the same style, importing from '../../scripts/decisions.mjs'. Cases on a fixture string, not on the real file: a 4-cell row, a 2-cell row, a row with a pipe inside a code span, a row with an escaped pipe, a row of 18,000 characters; each splits, passes the proof, has no line over 500; a row whose text is altered by one character after the split fails the proof; a 4-cell row whose date cell is not YYYY-MM-DD (a pipe misplaced) exits with its id.
