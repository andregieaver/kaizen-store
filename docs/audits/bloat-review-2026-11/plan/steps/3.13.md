# Step 3.13: Give the five file imports one core

Phase 3 (One of each) of `docs/audits/bloat-review-2026-11.md`. Effort M. Read [how to carry out a step](../README.md) first.

**Who:** a stronger model. The first commit is fully specified, but folding four more 300 to 640 line engines needs a reader who can tell a difference in wording from a difference in what is written, and the route commit moves a permission check from static text to run time.

After the step `insert into commerce.data_jobs` is written in one server file (five today), one import-flow component exists (four today) and the copy baseline holds at most 23 twin pairs (41 today).
