# Step 4.1: Build the admin kit and move action files onto the shared wrapper, area by area

Phase 4 (Tidy) of `docs/audits/bloat-review-2026-11.md`. Effort L. Read [how to carry out a step](../README.md) first.

**Who:** a stronger model. The kit's parts are a small design that every later screen copies, and each of the 20 action files has its own refusal shape and extra loads, so the wrapper move needs judgement per file; the ratchet commit is mechanical and can be done by a cheap model.

**Goal:** The admin kit has field, table, skeleton and form-foot parts; a per-file ratchet stops new class constants and hand-made tables in the admin and lets each file's count only fall; and none of the 23 action files with a guard wrapper of its own is left off storeAction() or platformAction().

**Why:** 296 class constants in 182 files and 154 hand-made tables in 116 files are spelled out per screen because the kit has no piece for them, and the one action wrapper carries 3 of 235 action files. After: the kit's parts exist with tests, both per-file counts can only fall and are 0 for a new file, no local guard wrapper is left (23 today) and unwrappedActionFiles is 209 or lower (232 today).

**Closes:** [CP-3](../../findings/copied-code/CP-3.md), [CP-7](../../findings/copied-code/CP-7.md). Each finding's file has the evidence.

## Do not

- Do not sweep the admin: no conversion of a file that is not otherwise being changed, beyond the loading files named.
- Do not change how a control looks: the kit takes its classes from src/components/admin/data/ui.ts; a visible change is a bug here.
- Do not make a kit part a client component, and do not import a catalogue into one.
- Do not weaken a guard: the key passed to storeAction() is the one the local wrapper checked, never a wider one ("owner" stays "owner").
- Do not move the storefront's action files (src/app/s/**): they have no member to guard.
- Do not raise a number in src/server/ratchet.baseline.json and do not edit it by hand.
- Do not edit a test's expectation; keep the old refusal sentence where a test asserts it.
