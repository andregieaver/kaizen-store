# Step 0.20: Stop asking for what does not change: a store's slug, the theme cards, the hosts list

Phase 0 (Before the doors open) of `docs/audits/bloat-review-2026-11.md`. Effort S. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model; a stronger one reads the diff before the push. Commits 1 and 2 are tiny and fully checked; commit 3 now gives every site's exact replacement, but it moves 24 reads in 17 files onto a helper cached for days and the int tests run without Next's cache, so a missing staleTag(storeIdTag) in adoptRequestSandbox() or a wrong slug at one site would pass every check. A smaller model may still do commits 1, 2 alone. *(Rating checked twice, 12 November; first written as cheap.)*

**Goal:** A store's slug by its id comes from one cached, tagged helper (not 27 hand-written statements), a theme's neighbours read the cached card list, and the list of store domains is parsed once per instance.

**Why:** `select slug from commerce.stores where id = $1` is production's most-called statement (560,090 calls in 78 days) and is written by hand on 27 lines; after, at most 3 lines hold it. marketPath() parses the whole hosts list 2 or 3 times per link (2,000 or more parses for 1,000 links); after, once.

**Closes:** [CP-2](../../findings/copied-code/CP-2.md), [SD-10](../../findings/storefront-server/SD-10.md), [CA-9](../../findings/caching/CA-9.md), [DQ-9](../../findings/queries/DQ-9.md), [CA-13](../../findings/caching/CA-13.md), [SF-12](../../findings/server-functions/SF-12.md).
