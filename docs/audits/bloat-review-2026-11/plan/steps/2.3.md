# Step 2.3: Draw each fixed style sheet once per document

Phase 2 (Load on demand) of `docs/audits/bloat-review-2026-11.md`. Effort S. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model; a stronger one reads the diff before the push. Commit 1 is mechanical and the scan and e2e checks catch a missed preview; commit 2 changes when styles reach streamed rows on every built page, so a stronger model should read that diff and look at a streamed page before it is pushed.

**Goal:** The fixed breakpoint sheet is drawn once per document by the layout, not again by every row, and (second commit) a page's rows share one part sheet with the theme layers read once per article.

**Why:** The 1,760-byte breakpoint sheet's href is in a three-row page's HTML 6 times today and the theme sheet's 3 times; a launch theme's home repeats it 9 to 13 times. After this step and step 2.2 each is there 2 times (once in the HTML, once in the payload), whatever the number of rows.

**Closes:** [CS-4](../../findings/styles/CS-4.md), [PM-7](../../findings/page-builder-model/PM-7.md). Each finding's file has the evidence.
