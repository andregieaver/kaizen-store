# Step 0.5: Load sharp, the font parser and the AI manager's engine when they are used

Phase 0 (Before the doors open) of `docs/audits/bloat-review-2026-11.md`. Effort S. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model; a stronger one reads the diff before the push. All three commits are mechanical and each has a scan test, but 12 picture modules and two server-action files change how they load, which only shows in a production-like run, so a stronger model should read the diff and the e2e results.

**Goal:** sharp and opentype.js are loaded by the first function that draws a picture or parses a font, the AI manager's server side is loaded when its panel is first used, and the MCP tool list is built when first asked for.

**Why:** Today 13 server modules import sharp or opentype.js at the top (the 21 MB image library loads with the proxy and about 740 routes), and /admin/[store]/orders loads 2,349 server modules because two action files import the AI manager's engine. After: 0 static imports of the two packages, and the orders route at or under 2,050 modules without src/server/owner-tools.ts.

**Closes:** [AS-1](../../findings/files/AS-1.md), [DP-2](../../findings/dependencies/DP-2.md), [SG-7](../../findings/server-module-graph/SG-7.md), [SF-9](../../findings/server-functions/SF-9.md), [DP-11](../../findings/dependencies/DP-11.md), [SG-15](../../findings/server-module-graph/SG-15.md), [SG-10](../../findings/server-module-graph/SG-10.md).
