### Commit 1 of 4: Work after the answer goes through afterOrNow() and afterOrLeave()

- **create** `src/server/after-or-now.ts`: `import "server-only";` and `import { after } from "next/server";`. Two exports, each with a comment that says when to use it. `export async function afterOrNow(work: () => Promise<unknown>): Promise<void> { try { after(work); } catch { await work(); } }`: in a request the work runs after the answer; outside one (a job, a test) after() throws and the work runs now. `export function afterOrLeave(work: () => Promise<unknown>): void { try { after(work); } catch { /* Not in a request: a scheduled job takes the work up. */ } }`. Read node_modules/next/dist/docs/01-app/03-api-reference/04-functions/after.md first and keep to what it says about where after() may be called.
- **create** `src/server/after-or-now.test.ts`: A Vitest unit test. At the top: `vi.mock("server-only", () => ({}));`, `const after = vi.hoisted(() => vi.fn());` and `vi.mock("next/server", () => ({ after }));`, then import afterOrNow and afterOrLeave from './after-or-now'. Cases: (1) outside a request (after.mockImplementation(() => { throw new Error('outside a request'); })): `await afterOrNow(work)` has called work once before it resolves; `afterOrLeave(work)` returns without calling work. (2) in a request (after.mockImplementation(() => undefined)): afterOrNow(work) and afterOrLeave(work) each hand work to after (after called with it) and neither calls work itself. work is a vi.fn(async () => undefined) per case.
- **edit** `src/server/{checkout,booking-changes,company-approvals}.ts`: List the blocks: rg -U -n 'try [{]\s*\n\s*after[(]' -A6 src --glob '!*.test.ts' (16 blocks in 12 files). Read each block's catch. Where the catch RUNS the work (`await work()` or `await fn()`): replace the whole try/catch by `await afterOrNow(work)`. That is checkout.ts (5 blocks), booking-changes.ts line 55 and company-approvals.ts about line 147. Where the surrounding function is not async, do not make it async: stop and report that block.
- **edit** `src/server/{design-tools,setup-tools,site-tools,store-drafts,stripe-webhooks,data-job-store,store-copy,search-cache}.ts`: Where the catch holds only a comment (the work is left to a scheduled job): replace the try/catch by `afterOrLeave(work)`. That is design-tools.ts about line 47, setup-tools.ts 110, site-tools.ts 126, store-drafts.ts 139, stripe-webhooks.ts 121, data-job-store.ts 419, store-copy.ts 357 and search-cache.ts 54.
