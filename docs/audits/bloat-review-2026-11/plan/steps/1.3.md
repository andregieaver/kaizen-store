# Step 1.3: Hold documents, stylesheets and requests on real store pages

Phase 1 (Budgets, so it stays removed) of `docs/audits/bloat-review-2026-11.md`. Effort M. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model; a stronger one reads the diff before the push. The tests are specified, but budgets on a real browser can wobble and a careless number hides a regression or fails pushes, so a stronger model should read the measured figures and the quiet-wait code before the push.

**Goal:** e2e/performance.spec.ts holds, on the real build, first scripts for 8 store routes within 3%, documents and payloads for 5 pages within 5%, stylesheets for 3 routes within 4% (raw and Brotli), the store home's style text, and for five pages on a phone the bytes on the wire, the late script files and requests to other hosts; e2e/prefetch.spec.ts holds router requests for five pages; and the ratchet holds two new counts.

**Why:** Today the visitor's budget counts a legacy file no modern browser loads, on 2 store routes with 14 to 16% of room, and no document, stylesheet or request count is held. After: 8 routes within 3%, 5 documents within 5%, 3 stylesheets within 4%, five pages' wire bytes within 4% with late scripts held exactly.

**Closes:** [SC-6](../../findings/storefront-browser/SC-6.md), [PL-13](../../findings/page-payload/PL-13.md), [PM-14](../../findings/page-builder-model/PM-14.md), [CS-3](../../findings/styles/CS-3.md), GAP-shopper-browser-s2. Each finding's file has the evidence.

## Do not

- Do not raise a budget to make a test pass, and do not set a budget above the stated room over its measured figure.
- Do not count nomodule script tags, and do not count scripts from the DOM after load for the first-scripts budgets.
- Do not use waitForLoadState('networkidle') for the quiet wait: a page that keeps a connection open never reaches it; use the three-second quiet rule.
- Do not delete the existing tests of e2e/performance.spec.ts (pictures eager and lazy, the blurred background, the speed beacon, the frame's name) or the assertions step 0.12 wrote in e2e/prefetch.spec.ts.
