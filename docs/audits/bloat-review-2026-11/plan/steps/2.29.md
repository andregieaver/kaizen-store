# Step 2.29: Let the builder paint first: the rich text editor and a store language load after

Phase 2 (Load on demand) of `docs/audits/bloat-review-2026-11.md`. Effort M. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model; a stronger one reads the diff before the push. Every edit is named and the builder specs catch a broken press, but it touches the shared storefront grid and many builder files, so a stronger model should read the diff before it is pushed.

**Goal:** The page builder paints before the rich text editor (Tiptap) loads, loads one storefront language only when a preview needs it, and the draft-order editor loads none; the admin's import walk forbids lib/i18n and lib/messages in admin client code.

**Why:** /admin/[store]/pages/[pageId] loads 3,303,372 bytes of script before first paint and 40 admin routes carry all four storefront languages (318,693 bytes); after the step the builder is at or under 2,300,000 bytes with no ProseMirror chunk in its first load and no admin route's first load holds a storefront language.

**Closes:** [AC-5](../../findings/admin-browser/AC-5.md), [AC-6](../../findings/admin-browser/AC-6.md), [BN-6](../../findings/client-bundles/BN-6.md), [TX-7](../../findings/interface-text/TX-7.md). Each finding's file has the evidence.
