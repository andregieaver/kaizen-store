# Step 0.8: Make a language translated by AI cost what it uses: at start, per document and per minute

Phase 0 (Before the doors open) of `docs/audits/bloat-review-2026-11.md`. Effort M. Read [how to carry out a step](../README.md) first.

**Who:** a stronger model. The registry is shared by the server's synchronous t(), server-rendered client components and the browser, and the change moves when a language is built and when an instance learns of an edit; getting the prerender rules and hydration right, and judging the hand check, needs more than following steps.

**Goal:** The start hook loads only a small reader of AI-translated interface text, reads the database with two statements whatever the number of languages, builds a language when t() first reads it, polls a one-row version stamp every ten minutes only where such a language is served, and sends the browser only the texts its components read.

**Why:** Today the hook reaches 383 source files (856 modules, src/server/ai.ts and auth.ts among them), reads each language with its own statement, polls every minute on every instance (1,440 statements a day each), and uiTextsFor() would put all 1,673 texts (92,809 bytes) in every document of such a store. After: 60 files or fewer, 2 statements at start, under 150 a day, and 114 texts under 9,000 bytes.

**Closes:** [SG-5](../../findings/server-module-graph/SG-5.md), [SF-3](../../findings/server-functions/SF-3.md), [SD-7](../../findings/storefront-server/SD-7.md), [TX-3](../../findings/interface-text/TX-3.md), [TX-12](../../findings/interface-text/TX-12.md), [TX-6](../../findings/interface-text/TX-6.md), [SC-13](../../findings/storefront-browser/SC-13.md), [PL-9](../../findings/page-payload/PL-9.md), [DQ-12](../../findings/queries/DQ-12.md), [DS-2](../../findings/database-shape/DS-2.md), [CA-12](../../findings/caching/CA-12.md), GAP-text-s7.
