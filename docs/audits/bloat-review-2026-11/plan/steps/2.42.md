# Step 2.42: Shorten the gate's type check

Phase 2 (Load on demand) of `docs/audits/bloat-review-2026-11.md`. Effort M. Read [how to carry out a step](../README.md) first.

**Who:** a smaller model; a stronger one reads the diff before the push. Each route is a few named lines and the rule for choosing is written out, but it changes what stands between a push and production, so a stronger model should read the trial's figures and the ci.yml diff before the second push.

**Goal:** The deploy gate's type check takes 60 seconds or less at the median under a 4 GB heap limit from a fresh checkout, by the first of three free routes that reaches it (the native TypeScript 7 compiler, a gate project without tests, or restored build info), and Vercel's build still runs no second check.

**Why:** The type check is one program of 8,003 files: about 3 minutes and a 7 GB heap limit, so the gate's three steps take 5 min 11 s; after the step the gate's type check has a median of 60 s or less over ten runs and the three steps together 90 s or less.

**Closes:** [TC-4](../../findings/tests-ci-build/TC-4.md), [TC-9](../../findings/tests-ci-build/TC-9.md). Each finding's file has the evidence.

## Do not

- Do not replace the 'typescript' package itself with version 7 during the trial: ESLint's parser and next build use it.
- Do not turn the type check back on in Vercel's build (no typescript.tsconfigPath there, ignoreBuildErrors stays): the build has 0.8 GB of room on the 8 GB machine.
- Do not use a larger runner, a paid build machine or any paid cache: GitHub's standard runner and its free actions/cache only.
- Do not exclude application code from the gate's project to reach 60 s: only tests, e2e, docs, scripts and the test configs.
- Do not cache .next/cache or the test-database template.
- Do not drop the whole-program check from the static job on route B: a type error in a test must still turn a job red.
- Do not skip the week: one fast run is not the trial.

## Stop and report if

- 'pnpm add -D ts7@npm:typescript@^7' finds no version 7, or its package has no tsc entry: skip route A, say so, and go to route B at once.
- The native compiler reports errors on a clean tree that tsc does not (or misses the seeded one): route A is out; put the differing errors in the decision.
- pnpm lint fails after the alias install.
- Route B's gate project reports errors the whole program does not (a non-test file that only compiles with a test helper's types): list the files; do not add them to the exclude list.
- No route reaches a 60 s median: report the three medians, remove the cache step if it did not help, keep the fastest route that is correct, and leave the step open in the tracker.
- The gate's type check runs out of memory under the 4 GB limit.
