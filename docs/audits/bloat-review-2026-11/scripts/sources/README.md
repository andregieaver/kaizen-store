# The review's working scripts and lists

103 files the reviewers wrote while measuring, kept as they were, each with `.txt` added so that nothing lints, type-checks or runs them. They are not tools: they have hard-coded paths (`<scratch>` is the review's working folder, which is gone) and hidden inputs. A step's brief names the one it needs and says what to make of it; step 0.1 turns the ones the plan's checks rest on into real scripts in `scripts/`.
