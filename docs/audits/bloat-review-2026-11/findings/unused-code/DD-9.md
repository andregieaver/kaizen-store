Two things keep them from being plain dead code. Second, and missed by the report: today's code still writes one old shape. upgradeBlock() treats a grid's columns given as {mobile, tablet, desktop} as pre-D179 (responsive.ts:459 and :498-504), and six places in production code write exactly that (src/lib/signature/kit.ts:85, meridian.ts:371, atelier.ts:284, kinetic.ts:311, src/lib/content-pack-pages.ts:77 and :162), as does the seed (supabase/seed.sql:273 and :279). Upgrade-on-read is also a written rule (docs/responsive-editing.md:56, docs/rules/admin/website.md:38) and e2e/pages.spec.ts:8 writes the pre-rows shape on purpose. Production holds 1,389 pages and 642 versions; how many are in an old shape is not known.
