## The fix

1. Write scripts/bundle-budget.mjs: read .next/diagnostics/route-bundle-stats.json and fail loudly if it is missing or is not an array of { route, firstLoadUncompressedJsBytes, firstLoadChunkPaths }. For every route under /admin compare with a committed baseline e2e/bundle-baseline.json ({ route: bytes }). Fail when a route is more than 15,000 bytes over its baseline; when a route has no entry; when the chunks shared by 90% or more of admin routes sum over a ceiling (1,130,000 today, 700,000 after AC-1); when any route passes the ceiling of its kind (builder 3,500,000, anything else 2,300,000 today, lowered as the fixes land). With --write it rewrites the baseline; without it, a route more than 15,000 under its baseline also fails until the baseline is rewritten, as scripts/ratchet.mjs does, so the numbers only fall.
2. Run it in CI after pnpm build in the signed-in job (.github/workflows/ci.yml line 249), the build the budget spec measures.
3. e2e/signed-in/admin-scripts.spec.ts lines 18-23: leave out script tags with nomodule, and reset the 7 budgets to the measurement plus 4% (each falls by 112,594). Add a document budget for the same 7 screens: the HTML's length.
4. Write the method into docs/performance.md (First scripts, signed in) and one line into CLAUDE.md's Commands (node scripts/bundle-budget.mjs after a build).
