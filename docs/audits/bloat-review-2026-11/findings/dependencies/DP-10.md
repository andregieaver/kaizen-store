- **Evidence:** sameSite() is a ten-line pure function in src/lib/same-site.ts. chat-route.ts re-exports it at line 38 ('kept here for the routes that import it from here') and also imports the chat agent, AI, support and the shop. Re-counted: 61 non-test files import chat-route.ts; 39 take only sameSite and 16 only fail and sameSite. Through that edge the four beacon routes reach 1,308-1,309 source files, with sharp, Supabase and opentype.js; without it 145-149 and none of the three. Six more routes fall to 325-424 files (admin creators/csv, redirects/404s/export, reviews/export, invoices/export, settings/close/export, and api/docs/feedback). Built, /api/visit loads in 1,025-1,062 ms and +177 MB RSS in a fresh process; /api/health in 223-226 ms and +64 MB. New: the beacon's own code bundled into one file loads in 549-590 ms, +58-68 MB heap, +158-160 MB RSS today, and in 209-215 ms, +26 MB, +80 MB with only this import changed.
- **Cost today:** About 1.0 s and 170 MB to cold-load a route whose job is one insert, against about 0.22 s and 64 MB for a lean route (this sandbox; an estimate for Vercel). Paid by: The server per new function instance whose first request is a beacon. Every shopper page view sends one while a store counts visits, so this is the dynamic call that grows fastest once shoppers arrive. On Vercel routes are grouped into functions and share loaded modules, so the real number of slow starts depends on that grouping, which was not measured.
- **Saving:** Measured on the beacon's own code as one bundle: 549-590 ms to 209-215 ms (62% less), heap +58-68 to +26 MB, RSS +158-160 to +80 MB. Expect the built route to fall from about 1.0 s and 177 MB toward the lean route's 0.22 s and 64 MB; estimate for Vercel until it is built.
- **Risk:** Low. It is the same function from the file that defines it; 55 import lines change and no behaviour. A missed importer fails pnpm typecheck once the re-export is deleted. The 45 importers that stay on the hub through other chains gain nothing and lose nothing.
- **Already tracked:** no. The storefront review's SD-1 names other hub chains (customers.ts, admin-text.ts, the proxy), not this one; code review 3.13 (domain folders, Open) is the general cure.
