- **Second check:** corrected.
- **Where:** `src/server/themes.ts:46`, `src/server/themes.ts:211`, `src/server/themes.ts:251`, `src/server/theme-installs.ts:343`, `src/components/admin/theme-editor.tsx:42`, `src/app/admin/(gated)/[store]/settings/design/actions.ts:88`, `src/app/admin/(gated)/platform/themes/[presetId]/workspace-actions.ts:227`, `src/server/design-presets.ts:1355`, `src/db/schema.ts:1304`, `docs/themes-unified.md:12`
- **Evidence:** 'Save as new theme' in the theme editor writes named settings to commerce.store_themes (D60; saveSavedTheme(), themes.ts:211-249; listed by listSavedThemes(), :46; deleted by deleteSavedTheme(), :251). The theme library keeps an own look as an install through addOwnLook() (theme-installs.ts:343-361), used by the Dream Factory and the brand tools. Both keep 'a look of my own under a name'. That is the one true overlap in the theme cluster, and it is small: themes.ts is 264 lines, the saved-theme functions about 100. Readers I found: the store's design pages (settings/design/page.tsx:55, themes/[install]/page.tsx:55), the platform's theme workspace (platform/themes/[presetId]/theme/page.tsx:28, workspace-actions.ts:227-233), one join for an old design use (design-presets.ts:1355) and a foreign key design_preset_uses.saved_theme_id (schema.ts:1304). The other tables of the cluster that production has not written are read and written by working code and are not dead.
- **Cost today:** Two save paths and two lists in one editor for the owner; one table and about 100 to 250 lines. Paid by: An owner's admin; anyone changing the theme editor
- **Saving:** Estimate: 100 to 250 lines and 1 table (store_themes). Not 1,000 to 1,500 lines and 6 tables.
- **Risk:** The two are not quite the same thing. A saved theme is settings that can be loaded over the live theme and saved again under the same name; an own look in the library is switched to or customised, carries the header, footer and CSS, and counts against the library's limit. So the editor works a little differently after the change, which the owner should see first. Noticed by themes.int.test.ts and by the design e2e.
