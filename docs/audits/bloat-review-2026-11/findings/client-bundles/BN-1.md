New file src/lib/public-env.ts with publicEnv() and the type PublicEnv written without zod: the URL is good when new URL(value) does not throw, the key when it is a non-empty string; the same error text ('Invalid or missing environment: NAME, NAME', URL first); the default source stays the two literal process.env.NEXT_PUBLIC_SUPABASE_URL and process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY reads, so Next inlines them.
