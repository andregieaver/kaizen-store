# PL-12 ✓ The default icon is a 26 KB .ico revalidated on every visit

What a page sends: document, payload and requests (`README.md` beside this file), part of `docs/audits/bloat-review-2026-11.md`.

- **Kind:** oversize. **Priority:** P3. **Effort:** S. **Confidence:** medium. **Step:** tolerated.
- **Second check:** corrected.
- **Where:** `src/lib/site-icons.ts:6`, `src/lib/site-icons.ts:13`, `src/lib/site-icons.ts:24`, `public/kaizen/favicon.ico`
- **Evidence:** siteIcons() links /kaizen/favicon.ico for every store without an icon of its own, the admin and Kaizena Flow's pages (site-icons.ts:6, 13). In routes.json it is the first request after load on every page measured: 25,931 bytes decoded, 11,080 as transferred locally (the verified report measured 9,292 gzipped and 8,802 with Brotli, four pictures of 16 to 256 px), Cache-Control public, max-age=0. Browsers fetch it at low priority and it blocks nothing.
- **Cost today:** About 9 KB on the wire per first visit per site, and a revalidation request on later visits. Paid by: A shopper's and an owner's browser.
- **Saving:** About 8 KB on the wire per first visit to any site without its own icon (estimate from a typical 32 px PNG), and the revalidation request on later visits once the files have a lifetime.
- **Risk:** Low.

## The fix

1. Add public/kaizen/icon-32.png (about 1 KB) and public/kaizen/icon-180.png, drawn from the same mark.
2. src/lib/site-icons.ts:13: when there is no favicon return { icon: [{ url: '/kaizen/icon-32.png', type: 'image/png', sizes: '32x32' }], apple: [{ url: '/kaizen/icon-180.png', sizes: '180x180' }] }. Keep KAIZEN_ICON for faviconRedirect() (line 24), which serves browsers that ask for /favicon.ico unprompted.
3. Give public files a cache lifetime with the assets work (AS-5 of this review: public files have none): a headers() entry in next.config.ts for /kaizen/:path* with public, max-age=86400, or versioned file names with a year.

**Done when:** A cold load of /s/demo/no asks for no file over 2,000 bytes as its icon (25,931 today, by measure-routes.mjs's after-load list).

**Tests and rules that hold today's behaviour, and change with it:**

- Rule D62 (sites' icons are navigation.favicon, linked by siteIcons() in every layout): kept; only the default changes.
- src/lib/brand.scan.test.ts (no old name in a string) and any test that names KAIZEN_ICON (rg -n 'KAIZEN_ICON|kaizen/favicon' src e2e).

**Notes:** True but small: 9 KB at low priority, smaller than any document. Not worth a change of its own; do it with AS-5 (assets), which gives public files their cache lifetime.
