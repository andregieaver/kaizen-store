The server code every route loads (`README.md` beside this file), part of `docs/audits/bloat-review-2026-11.md`.

- **Kind:** eager. **Priority:** P1. **Effort:** S. **Confidence:** high. **Step:** 0.5.
- **Second check:** added by the planner, not checked a second time.
- **Where:** `src/server/settings.ts:22-25`, `src/server/settings.ts:13`, `src/server/connect.ts:5`, `src/server/ai.ts:26`, `src/server/mollie.ts:23`, `src/server/google-reviews.ts:20`, `src/server/instagram.ts:17`, `src/server/pipedrive.ts:48`, `src/lib/secret-box.ts:15`
- **Evidence:** encryptionKey() is three lines in settings.ts (22-25): parseKey(process.env.SETTINGS_ENCRYPTION_KEY), with parseKey from src/lib/secret-box.ts:15. On all 59 storefront pages ai.ts and mollie.ts import settings.ts. Alone, before SG-1, the cut changes nothing (2,498 -> 2,498): the cycle brings the same files another way. No test mocks ./settings or encryptionKey (rg finds none).
- **Cost today:** About 205 modules and 260 KB of server code (settings.ts, connect.ts and the Stripe SDK's 189 modules and 212 KB) on every route that reads a secret or asks for an AI connection but takes no payment: 26 storefront pages, about 60 handlers, the sitemap and robots routes. ## The fix

1. New file src/server/encryption-key.ts: import 'server-only'; import { parseKey } from '@/lib/secret-box'; and the function and comment now at src/server/settings.ts:22-25.
2. src/server/settings.ts imports encryptionKey from the new file for its own uses (lines 287 and 298) and does not re-export it, so no file can take it from the settings module again.
3. Change the import path in the 18 files that take it alone (rg -l 'import \{ encryptionKey \} from "(\./|@/server/)settings"' src) and split the import at src/server/pipedrive.ts:48 (encryptionKey from './encryption-key', listStaff stays).
4. Add to the guard of SG-14: src/app/s/[store]/[market]/layout.tsx and page.tsx, src/app/api/shop/tiles/route.ts and src/app/robots.txt/route.ts may not reach the stripe package by static value import (an exception list holds the routes that still do until SG-1 and SG-5 are in).
5. Build and read the done-when.

**Done when:** rg -n 'export function encryptionKey' src/server/settings.ts prints nothing, and a new next analyze export shows /s/[store]/[market] with no ~/stripe module among its sync modules (today 189 modules, 212 KB) once SG-1 and SG-5 are also in.
