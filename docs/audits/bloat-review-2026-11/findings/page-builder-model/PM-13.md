## The fix

1. Nothing to remove on engineering grounds. Put the question to the owner under the Homer and Lisa rule: should a new owner see these near-twins as one in the palette (an FAQ as an accordion with a questions switch; one button with an optional second; one form with a newsletter switch)?
2. If the owner says yes for a pair: keep both types in the stored model at first and merge only the palette's entry and the editor's fields (the second type becomes a preset of the first). That changes no stored page, no theme and no page studio pattern.
3. Only if a type is to leave the model: do it inside code review step 3.2 (one definition per block), after PM-9's count of stored shapes, with a one-off rewrite of stored documents, the six signature themes (src/lib/signature), the templates and the page studio's patterns (src/lib/page-ai.ts) in the same change.
