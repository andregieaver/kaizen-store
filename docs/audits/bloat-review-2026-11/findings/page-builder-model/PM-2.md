Estimate: at production's average (29 pages of about 3.3 KB) one store's list is about 100 KB of the instance's 50 MB. Paid by: The database; the server per cold instance, per render and per resume; the build

How much of production's 781 s goes cannot be read from the statistics, and that time is not shopper traffic.

Describe the row with col and read it through typedRow() (the rule for new reads).
2. src/server/pages.ts: add publishedPageIndex(owner, type = 'page'), same cache settings and tag, same where and order as listPublishedPages but no document: id, slug, published ->> 'title' as title, the translated titles as one small object (jsonb_object_agg over published -> 'translations' of each locale's title), published_at, first_published_at, published ->> 'blogId', published -> 'categories', published -> 'markets', and the searchEngines and aiAssistants flags. Add a small pure helper indexTitle(row, locale) that picks as localizePage() does, with a unit test that holds the two together.
