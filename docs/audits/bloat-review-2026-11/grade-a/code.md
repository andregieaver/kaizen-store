Part of `docs/audits/bloat-review-2026-11.md`. **Today: C.** The steward's C stands. - Invoice PDFs: made ahead by the scheduled job, so 'Try again' is true (recommended, step 3.7), or made on the first download, with the route nothing calls removed?
- Live drills: a Run drills button on the platform's store page, or a console tool asked for by SQL, with the rule saying so?
- Three picture sizes or four? With 480, 800 and 1,600 px a full-width picture on a 3x phone needs about 1,170 px and takes the 1,600 px file. A 1,200 px copy would roughly halve those bytes (an estimate from the pixel count) and adds about a quarter to a picture's stored bytes and one more upload. Sizes are fixed when a file is stored, so this is cheapest to decide with step 0.33.
