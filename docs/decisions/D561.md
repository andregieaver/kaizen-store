# D561: A countdown timer and animated stats

**A countdown timer and animated stats (11 November 2026, `src/lib/countdown.ts`, `src/lib/stats-count.ts`, `CountdownBlock`, `StatsBlock`, `src/components/countdown-view.tsx`, `src/components/stats-view.tsx`).** The owner asked for two more components; asked, they chose a countdown to a fixed date and time that hides at zero, and stats whose figures the owner types, on stores' pages and Kaizena Flow's own. **Countdown:** days, hours, minutes and seconds left until `endsAt` (an ISO moment in
UTC, chosen in the owner's browser's time zone), the same for every visitor, with the owner's words above it, in boxes or plain numbers. A timer that starts again for each visitor is not offered: it would announce an urgency that is not there, which the Unfair Commercial Practices Directive forbids (Annex I, 7).
It is drawn only in the browser (the visitor's clock, one shared tick a second through `useSyncExternalStore`, so the server's HTML and the first render agree), and once the end has passed it draws nothing, so a past offer is never announced; in the builder an ended or unset one shows zeros. A screen reader is given the end as a date, not a number every second.
The units' words are each language's own (`Intl.NumberFormat` unit names), so no new interface text was needed. **Animated stats:** up to eight figures, each a number (its decimals as typed), words before and after it and a label, `columns` across on larger screens (at most two on phones); each counts up from zero, easing out, when a third of the list is in view, in `duration` seconds (two unless set), and rests on the figure as typed.
The server's HTML holds the figures, so without scripts, for search engines and for visitors who prefer less motion they are simply there; a screen reader is given the figure, never the count. The figures are the owner's claims; the settings ask for figures they can stand behind. Both translate with the page (the countdown's words, each figure's words and label) and take the component's text size and colour. Tests: `countdown.test.ts`. No migration.
