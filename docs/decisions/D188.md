# D188: A modal that is left out of the site says so in the builder

**A modal that is left out of the site says so in the builder.** A row's modal exists on the site only when something in the row shows (`rowShows()`, now in `page-content.ts`, the one rule of the site, a header's overlay and the builder): a newsletter or email form with no address under *Send to* shows nothing (D93), so a modal whose only component is one is dropped from the page like any empty row, its dialog is not there, and neither a link to `#modal-{key}` nor its class can open it.
The modal row's badge on the canvas, its Modal settings and a button's *Opens a modal* choice now say it (`MODAL_LEFT_OUT`). The behaviour itself is kept: a form that cannot deliver is never shown.

Date: 2026-10-09

Asked as a question by the owner (a link to `#modal-newsletter` and a class both did nothing). Reproduced against a build: with the form's address the link and the class open it; without, no dialog is in the page; a link on another page than the modal's row does nothing either (a modal in the footer or header is on every page). No migration.
