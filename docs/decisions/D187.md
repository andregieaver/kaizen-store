# D187: Several lines of columns in a row

**Several lines of columns in a row.** A row's columns can sit in more than one line, one under another, as Beaver Builder's column groups do. `PageRow.moreLines` lists the layouts of the lines under the first (`layout`), up to six lines of six columns; `columns` stays one flat list, line after line (`columnLines()`, `rowLayouts()`; `pageInput` refuses a count that does not add up), so a row of one line, every page saved before this and the part stylesheet's class hashes are unchanged.
In the builder a column dragged by its handle can be dropped on a *New line* strip above or below a line, or among the columns of any line of any row; the sidebar's Rows tab has a *Column* tile, dragged in beside existing columns or pressed to add. Whenever columns are added to or taken from a line, that line shares its width evenly again and any share set by hand (at any screen size) is taken back, as the owner asked; a reorder inside a line keeps them.
All edits are the pure functions in `src/lib/page-rows.ts`. The site draws a box per line inside the row's grid (`rowGridStyle()`: the row a flex column, each line its own grid or stack at each screen size), so the phone stacks every column in order.
