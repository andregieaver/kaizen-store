**Old admin redirects and the bookings and boxes twin switch removed (bloat review step 0.37; 16 November 2026).** The eight redirects from Work's old store-level addresses (D123) and the themes' old admin addresses (D273) are gone from `next.config.ts`: before the platform opens only the team held an old address, and no email, push, docs article, AI tool or link in the code names one.
Bookings and subscription boxes are switched in `stores.features` alone: `setBookingsModule()`, `setDeliveriesModule()` and `legacyModule`, which nothing called, are deleted; `Store.bookingsOn` and `deliveriesOn` always read the features.
