# D680: A/B tests made plain, step 4c

**A/B tests made plain, step 4c: the AI looks at the versions (`docs/ab-testing.md` phase 15; 16 November 2026, `src/server/page-looks.ts`, `src/server/experiment-tools.ts`).** `look_at_page` (D310) takes a page test's version by its id: `findLookPage()` and `lookDraft()` accept a page of type `variant` whose test targets a page of the same store, drawn as a page, with the checker's and the claims filter's findings.
`explain_results` answers `to_see_each_version` with each version's page id; the ab-test skill says to look before a test starts. Not the planned `look_at_versions` tool: the tools a turn carries are at 128 (`tool-budget.ts`), and an id in a tool's answer changes no tool's description, so the tools' fingerprint is as before and no eval run is needed. A version of a header, footer or product layout is not looked at.
