# D233: The chat agent's picture frame

**The chat agent's picture frame.** Owners frame the agent's picture on the site from the agent form (`/admin/{store}/chat`, `/admin/platform/chat`, `ChatAvatarFields`): a background (none, a colour, or a two-colour gradient with a direction), a border (0 to 8 px, a colour) and a shadow (none, soft, medium, strong, glow, a colour). Kept as `chat_agents.avatar_style` (jsonb, null for the standard look) and copied by `duplicate_store()`.
Read only through `cleanAvatarStyle()` (`src/lib/chat-avatar.ts`: `#rrggbb` colours, whole numbers in range, the listed shadows, else the default), drawn only by `avatarFrameStyle()` as an inline style on the widget's picture, so owner data never becomes CSS of its own; the module has no zod, as the visitor's widget loads it (D211). The fill shows through a picture's see-through parts and replaces the accent behind the chat icon when there is no picture.
Migration versions: `20261014171811_chat_avatar_style`, `20261014171828_chat_avatar_style_copy`, applied by CI on 14 October 2026; advisors checked after: no new finding.
