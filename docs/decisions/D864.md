**The admin shell and the visit beacons list fewer server references (bloat review step 2.24; 20 November 2026).**
`node scripts/route-budget.mjs --references` prints the server-reference manifest per source file, per route kind and the references
listed by more than 500 routes. The admin shell imports only the four actions it calls (`signOut` in `(gated)/shell-actions.ts`, the
language, colour and view switches in `(owner)/account/shell-actions.ts`; unwrapped, as they run for any signed-in account, so the
ratchet's unwrapped action files rose 231 to 233). The five visit beacons read the store through `visitStoreOf()` in `store-facts.ts`
(one statement shared with the proxy's) and reach no cached read and no action. The A/B tests' cached reads moved to
`experiments-read.ts`. On a signed-in build the manifest fell from 11,953,568 to 9,880,996 bytes, its entries (route by reference) from
92,655 to 76,313, the admin's median references per route from 135 to 96, and each beacon's from 4-6 to 0; the files a beacon reaches
fell from 88-137 to 39-46 (route budget lowered). The subscription reminders job reaches 1,501 files (named among the heavy handlers).
The brief's targets (40,000 entries, an admin median of 60) need a new plan: the admin's routes reach most cached reads through chains
of imports between files that write, and through `import()`, so splitting reads apart moves little; the remaining features of commit 4
and commit 5 wait for it. Live from 20 November (207cbbda7). Idle cost: none. Commits 96b38757c..207cbbda7.
