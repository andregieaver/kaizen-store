# D135: Delivery options at checkout

**Delivery options at checkout** (`docs/shipping-carriers.md`, `src/lib/delivery-options.ts`, `src/server/delivery-options.ts`, `DeliveryChoice`): the shopper gives a postal code at checkout and chooses between the market's flat rate and the services of the store's carrier (Posten / Bring for Norway), with pickup points for service 5800.
Each offer is kept as a `delivery_quotes` row priced as shown (carrier price + standard VAT + the store's percentage and amount, in the country's currency), and the chosen one (`carts.delivery_quote_id`, read by `chosenDelivery()`) is the basket's shipping rate in both `cartSummary()` and `placeOrder()`, so they agree and no carrier is called while placing an order.
The flat rate stays as the default and the fallback when Bring does not answer, so a store keeps it set up; a subscription ignores the choice. The order keeps `orders.delivery` and names the service to Stripe, the pages and the emails; the admin booking starts with the shopper's choice. Owners set services, markup, free-above and default weight on the carrier's page.
