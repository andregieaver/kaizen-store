# D651: A page the autopilot published is rolled back after a clear fall

**A page the autopilot published is rolled back after a clear fall (`docs/100-day-challenge.md` F4; 16 November 2026, `src/server/autopilot-watch.ts`).** The watch (D628) undid prices, codes, campaigns, the theme and ad budgets; a page the autopilot published was judged but could not be undone.
`publish_page` is now in `REVERTIBLE_TOOLS`, and `undoPage()` puts it back through the page's own versions (D305): the page is the one its publish entry names (`store.{type}_published`), the version that was live before (the newest `published` version but one) is published again through the page builder's own `savePage()` (its fonts, live before, are installed already), and a page the autopilot made live for the first time is taken off the site with `unpublishPage()`.
It acts only while what is live is still the autopilot's newest published version, the draft is the same (nobody edited it since), and no one published or unpublished the page after the change (the audit log); otherwise the verdict is kept with nothing undone, as for a price someone changed. Errors per hour stay unwatched: the store's errors are counted per day only, too coarse to blame one change. No migration.
