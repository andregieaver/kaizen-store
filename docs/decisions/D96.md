# D96: Kaizen Life's assistant works with the owner's stores through the store's MCP server, and asks the store's own assistant; what it would change waits for the owner

**Kaizen Life's assistant works with the owner's stores through the store's MCP server, and asks the store's own assistant; what it would change waits for the owner.** `/api/mcp` (Streamable HTTP, JSON-RPC, plain JSON answers; `src/server/store-mcp.ts`) takes an access token from the store's own Supabase OAuth server, issued to the Kaizen Life client (`KAIZEN_LIFE_CLIENT_ID`; the `client_id` claim is checked, with the issuer and expiry) for an account that owns stores that are not closed;
anything else gets 401 pointing at `/.well-known/oauth-protected-resource` (RFC 9728). Its tools are `list_stores`, `ask_store_assistant` and every owner tool (D94) with the store it is for, one of the owner's, so an owner of several stores connects them all at once.
Tools that read answer; tools with a gate are never run from here: they are kept in the owner's "From Kaizen Life" conversation (`assistant_conversations.source = 'kaizen-life'`, one per store and owner) and approved or declined in the admin like the assistant's own. `ask_store_assistant` is a turn of the store's assistant in that conversation (`runTurn(..., fromKaizenLife)`), so it never asks Kaizen Life back.
The other way round, an owner connects Kaizen Life for the assistant under Your account: an OAuth code flow with PKCE against Kaizen Life's Supabase OAuth server, as the client Kaizen Store has there (`KAIZEN_LIFE_ISSUER`, `KAIZEN_LIFE_OAUTH_CLIENT_ID`/`_SECRET`), the state bound to the account in the `kaizen_life_link` cookie, and the tokens encrypted with `SETTINGS_ENCRYPTION_KEY` in `commerce.kaizen_life_links`, one per account (`src/server/kaizen-life-link.ts`).
While connected, the owner assistant also has `ask_kaizen_life`, which calls Kaizen Life's MCP tool `ask_life_assistant` and passes its words on; it is not an owner tool, so `/api/mcp` never serves it, and it is left out of turns Kaizen Life asked for. Kaizen Life decides what its assistant does for the store: its calendar, tasks and plans, never health, money or contacts. The store works without Kaizen Life.

Date: 2026-09-28

Asked for by the owner with D94 and D95: the two assistants talk to each other, owners only, all of an owner's stores. MCP is what Kaizen Life's agent already speaks, and Supabase's OAuth server issues and revokes the tokens with no new service; keeping changes behind the owner's approval here means another product's model never publishes, sends or spends in a store.
