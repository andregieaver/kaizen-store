# D646: Return labels and handling in contribution profit

**Return labels and handling in contribution profit (`docs/100-day-challenge.md` E1; 15 November 2026, `src/server/analytics-totals.ts`, `src/lib/analytics-finance.ts`, `src/lib/order-profit.ts`).** Contribution profit, which the challenge scores on, left out two costs of every order. **Return labels**: each booked return label (`returns.label_cost_minor`, kept with VAT in the order's currency) is counted by the day it was booked, the standard VAT rate of the order's country taken off as
shipping takes it (`commerce.vat_rate(market, 'standard', booked)`); test labels and copied or hosts' orders never count, and a label in a currency with no rate is left out of the costs only. **Handling and packaging**: a new cost per paid order with something to send (`analytics_settings.handling_cost_minor`, set beside the shipping cost on Analytics settings, "Handling and packaging per order"), the warehouse's pick-and-pack fee in the challenge (C1).
Both are their own lines on the Finance page (shown when set or booked, in the "where it went" view too) and in an order's own profit, and come off contribution in `contributionOf()` and the statement, which still reconciles. Kaizena Flow sells plans and sends nothing, so the platform has no use for either.
