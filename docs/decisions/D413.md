# D413: Two additions to the page builder, asked for by the owner on 1 November 2026

**Two additions to the page builder, asked for by the owner on 1 November 2026.** **Before and after**: a new component, two pictures over each other and a centred slider the visitor drags (or moves with the arrow keys) to reveal either; the slider is the browser's own range input laid unseen over the picture, so it works by pointer, touch and keyboard and is named for screen readers; it is drawn at the before picture's size or a chosen crop, never enlarged (as a picture, D151), and shows only
with both pictures; the words in the corners are the owner's or the visitor's language's "Before" and "After", or none. **Remove background**: every picture field in the builder that has a picture offers it, using the library's AI edit (D349, `remove_background`) on the picture by its address; only a picture the site's library holds can be edited (another store's, or one only linked, is refused with the reason), the result is a new library picture marked as the AI's and the original is kept.
Found the same day: both sites had a picture model (`gpt-image-1.5`) and no separate edit model, so the button never showed; a gpt-image picture model at OpenAI now edits too when no edit model is chosen (`pictureEditModel()`), and a removed background is asked for see-through as a PNG, which the prompt alone does not give. Rules: `docs/rules/admin/website.md` (Before and after; Remove background on picture fields).
