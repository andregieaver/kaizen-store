# D194: A table component in the page builder

**A table component in the page builder.** A *Table* block: rows and columns of text cells, an optional header row, a title, row headers and shaded rows. Rows and columns are added and removed from the grid in the block's settings (a button per row and column, and Add row and Add column). On a phone it stacks by default (each row a card, every value under its column's name) or scrolls sideways; from Medium it is a table.
