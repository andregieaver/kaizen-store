# D258: Showcases

**Showcases: each look of a theme on a store of its trade (the theme showcase plan, phase 1 step 3, `docs/theme-showcase-phase-1.md`).** A theme's listing names the content pack each of its looks is shown on (`pack` for its own look, `presetPacks` by preset key), chosen on the theme's details page (*Shown on*) or, for a launch theme, in the code; it is the listing's and not the version's, so it changes without a new version.
The theme page previews each look on its pack's published store template (the Standard store while that pack is not published), says the trade under each preset and which demo store the frames show, and a card names the trades its looks are shown on.
The launch themes get presets as version 2: Calm (on fashion; Sand on beauty, Ink on electronics, Sage on home), Hearth (food; Olive on home, Blush on beauty), Signal (fashion; Volt on electronics, Cobalt on services), Fjord (home; Mist on beauty, Pine on services), each passing the theme checks without a contrast warning; the switch test goes through every one.

Date: 2026-10-16

Step 3 of "Then start phase 1": a preset is shown where it belongs, a fashion look on a fashion store. No migration (the listing is jsonb). The packs show only once a platform admin has set them up, made their pictures and published them in production.
