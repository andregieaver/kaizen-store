# D361: The installable admin and push

**The installable admin and push (wave 9 unit H, `docs/wave-9-platform.md` section 3, H); built.** The admin is a web app: `/admin/manifest.webmanifest` (name, `/admin` as start and scope, standalone, Kaizena Flow's own icon, D62) linked from the admin's root layout, and a service worker at `/admin/sw.js` (`adminServiceWorker()`, `src/lib/admin-sw.ts`, `Service-Worker-Allowed: /admin/`) registered by the signed-in shell (`AdminServiceWorker`).
It keeps only `/admin/offline` and the default icon in Cache Storage (`kaizen-admin-shell-{version}`, in `KNOWN_COOKIES` as a staff item), never a signed-in page or data, answers a page load of the admin it cannot fetch with that page (English and Norwegian, as no account is known offline), shows a push's notification and opens its address on a press, only an address of the admin on the same site.
Web Push uses the `web-push` library (3.6.7, pinned) with the VAPID keys of `vapidEnv()` (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, Kaizena Flow's site by default); without both keys nothing is offered.
On Your account, *Notifications on this device* lists the stores whose orders the person reads (`orders:read`), each a switch: turning one on asks the browser's permission, subscribes the device and keeps it (`commerce.push_subscriptions`: account, store, endpoint, keys, the device's name; at most 10 a person and store; written only by `src/server/push.ts`); the endpoint must be https on a push service's own host (`isPushEndpoint()`: FCM, Mozilla, Apple, Windows), as the server POSTs to it.
A paid order's staff alert event (`order.paid`), after its emails, sends `sendOrderPush()`: to each device of the store whose person still reads its orders (read again by `passMembership()`; else the device is removed), its number and total only in the person's admin language (`staffEmails.push`), opening the order, kept six hours by the push service; a 404 or 410 removes the device, five failures in a row too. Never copied (`never`), staff data in `PERSONAL_DATA`.
`platform.mobile-admin-app` stays partial (offline shows a page, not the shell; no e2e at 390 px; the VAPID keys are to be set). Migration versions: `20261028133214_push_subscriptions` (applied by CI on 28 October 2026, run 700; advisors to check).
