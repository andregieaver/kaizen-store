# D202: Dividers and rows are dragged separately

**Dividers and rows are dragged separately.** A section divider in the table's settings grid has its own handle and moves by itself; dragging a row no longer takes the divider above it along (and a row's handle moves only that row). A move that would leave two dividers together, or one at the end, is refused.
