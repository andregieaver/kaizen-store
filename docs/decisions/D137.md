# D137: Porterbuddy is connected

**Porterbuddy is connected** for delivery windows at checkout, booking, labels and status (`docs/shipping-carriers.md`, `src/lib/porterbuddy.ts`, `src/server/carriers/porterbuddy.ts`, `src/server/porterbuddy-shipping.ts`), on the store's own API key.
A window is a checkout quote (`delivery_quotes.window_*`, held until the carrier's `expiresAt`), priced as a `carrier`-priced service (VAT and markup on Porterbuddy's price; a `displayPrice` already has VAT) and listed by date; the order keeps `orders.delivery.window`. Booking asks for the window again and books it with the fresh token (the shopper's has expired by then), books nothing if it is gone, and never marks an order sent in the test environment.
Labels are fetched when printed and never kept (`carrierLabel()` serves Bring and Porterbuddy).
