# D207: Menu links answer the pointer with a line or a background, and show the page the visitor is on

**Menu links answer the pointer with a line or a background, and show the page the visitor is on.** A menu component's links had only a light grey shade on hover.
Its Style tab now has *Hover and active*: a line above, below or both, or a background, either growing from each link's centre or as one marker gliding from link to link; the line's or background's colour (the theme's accent unless set) or a gradient for the background, the line's thickness, the background's corners, and the links' text colour.
The link of the page shown carries the same effect unless switched off; it is marked in the browser (`aria-current="page"`), so pages stay cached and the same for all. A gliding marker needs script; without it each link grows its own. Times and easing follow the hover timing (D206).
