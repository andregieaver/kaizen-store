# D31: Stores have discount codes for shoppers, and Kaizen has discount codes for stores' plans

**Stores have discount codes for shoppers, and Kaizen has discount codes for stores' plans.** A store's code gives a percentage, an amount per market (in its currency) or free shipping; on everything or chosen products; with an optional minimum order per market, start and end (Norwegian time), a total number of uses, and one use per customer.
Shoppers type it in the cart, which checks it against the basket exactly as checkout will and says why a code does not apply; checkout checks it again under a row lock, so two orders cannot take a code's last use. A code counts as used by every order that got it and is not cancelled, waiting for payment included; a cancelled checkout gives the use back. The discount is spread over the lines it applies to (a percentage per unit, an amount in proportion) and each line's VAT is on what is paid.
Stripe gets it as a one-time coupon on the store's account for that checkout alone, for single payments and subscriptions alike; free shipping on a single payment is simply a lower shipping price. A percentage can also lower every renewal of a subscription: the subscriber's price itself is lowered, for good. Orders, emails, My account and the admin show the discount and the code.
Kaizen's codes for plans are a percentage or an amount per plan currency, for the first payment, some months or for good, with an optional expiry and number of uses; each is a coupon and a promotion code in Kaizen's Stripe account (in every mode with keys), and Stripe applies it to the plan's invoices. Owners type one on their Plan page: it applies at once to a running plan, or is saved and used when they choose one (in Stripe Checkout or when an admin assigns a plan).
Platform admins make and switch codes on the platform's Discounts page, and can put one on any store's plan.

"Once per customer" needs the shopper signed in to My account: before payment Kaizen does not know who is buying otherwise. Any code can be changed or deleted at any time, used or not: orders keep the code's text and the amounts they got, so changing or deleting a code never changes an order (deleting only unlinks it).
Stripe's coupons cannot change, so changing what a platform code gives retires its coupon and promotion code in Stripe and makes new ones under the same code; a plan that already has it keeps the old terms, and a store whose code was still waiting for a plan loses it when the code is deleted. Codes are case-insensitive and stored in capitals; store codes may use Æ, Ø and Å, Kaizen's codes only A–Z (Stripe). Stacking several codes on one order is not offered.
Codes typed on Stripe's own checkout page are not offered either; codes are entered in Kaizen only, so Kaizen always knows which code a plan has.
