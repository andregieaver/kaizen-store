# D198: Section colours; the admin's table styling stays out of the page canvas

**Section colours; the admin's table styling stays out of the page canvas.** A table's section dividers take a text and a background colour. The admin's own table-header, row-hover and tabular-figure styling now carries the canvas exclusion every admin restyling has, so a table in the page builder shows the colours set on it, as the site does.

Date: 2026-10-10

Reported by the owner (header colours showed on the site, not in the builder). No migration. `admin-css.test.ts` holds the scoping; `table-view.test.ts` the colours.
