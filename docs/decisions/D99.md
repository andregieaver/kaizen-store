# D99: Light and dark are each person's to choose

**Light and dark are each person's to choose: in the admin for every account, and in a store for its visitors where the owner lets them.** A choice is `data-color-mode` (`light` or `dark`) on `<html>`; without one the device decides (`src/lib/color-mode.ts`).
Everything follows it: globals.css's colours and `color-scheme`, Tailwind's `dark:` (a custom variant: the choice, else the device unless light was chosen), store themes (`themeCss()`: the store's mode, then the other colour set where a visitor chose it, on `<html>` or, where the element has no mode of its own, around it, as the builder's canvas has the admin's), logos for dark backgrounds (both drawn and one shown by CSS, `.for-light-colors`/`.for-dark-colors`, the hidden one never fetched;
`darkBehindLogo()` now says which suits each colour set) and Stripe's checkout and onboarding (`showsDark()`). A store always light or dark marks `<html>` with it, so `dark:` no longer follows the device there. A page's first script (`colorModeScript()`) sets a saved choice before anything is drawn.
In the admin (Kaizen's platform admins, store owners and staff alike) the choice is the account's (`accounts.color_mode`: `system`, `light` or `dark`), set under Your account (Light or dark) or with the switch in both admin headers, kept in the browser too (`kaizen_admin_color_mode`) for the first paint and brought in line with the account on each admin page (`AdminColorSync`), so it follows the person to any device.
Stores: Design has Let visitors choose light or dark (`ThemeSettings.visitorSwitch`, off unless chosen); the standard header then shows a switch, and a header of the owner's own takes the Light or dark site part; a visitor's choice is kept in their browser per store (`color_mode_{store}`, necessary, listed on the cookie page only while the switch is on), and choosing the store's own colours again forgets it.
With the switch on, the editor's readability warnings and preview cover both colour sets. Kaizen's own site keeps following the device.
