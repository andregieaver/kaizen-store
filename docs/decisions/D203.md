# D203: A long table scrolls inside itself, with its header and section titles kept in view

**A long table scrolls inside itself, with its header and section titles kept in view.** In a pop-up a table is as tall as 70 % of the screen (or the height set in its Style tab) and scrolls in a box of its own, so the pop-up needs no scrollbar; the header row stays at the top and each section title stays under it until the next one takes its place. *Scroll inside the table* is *In pop-ups only* unless set to *Always* or *Never*.

Date: 2026-10-11

Asked for by the owner. No migration. `e2e/table-modal.spec.ts` holds it in a real browser, `table-view.test.ts` the markup.
