# D643: Thirteen duplicate indexes dropped, and a test that stops the next one

**Thirteen duplicate indexes dropped, and a test that stops the next one (bloat review step 0.26; 15 November 2026).** Each was led by another index of its table (or, for `orders_retention_idx` and `orders_invoice_candidates_idx`, had exactly the key of `orders_store_placed_idx`), and each cost every write one more entry: on orders (2), order_lines, visits, and nine smaller tables.
The hot tables' four go in a `-- kaizen:no-transaction` file with `DROP INDEX CONCURRENTLY IF EXISTS`; the other nine in a plain one; none is unique or a constraint's. `src/db/index-duplicates.test.ts` fails when a new index is led by another of its table.
