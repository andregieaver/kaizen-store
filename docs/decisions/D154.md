# D154: The parity tracker

**The parity tracker: Kaizen's gap to Shopify is data, checked by a test.** `docs/parity/rows/*.json` holds one row per Shopify feature (254 rows after removing 12 duplicates that the first report counted in two or three domains): the Shopify side (tier, what it does, the page it was read from and when), Kaizen's rating (full, partial, missing), a weight, the gap, a bucket (A build in-house, B needs a third party's approval, C needs a strategy decision, D not reachable by code), a wave, testable
acceptance criteria and evidence (the files and tests that hold it, or `untested: true` as counted debt), and a history of every rating change.
`src/lib/parity.ts` is the pure code (rules, scoring, per-wave projections, report renderers), `pnpm parity` prints the figures, `pnpm parity:write` regenerates the report's tables between the `parity:generated` markers, and `pnpm parity:check` and `src/lib/parity.test.ts` fail when a row breaks a rule (a Full row without existing files and a test or an `untested` flag, a rating change without a history entry, a fetched Shopify claim without a page and a date) or when `docs/shopify-parity.md` no
longer equals what the data renders. `.claude/workflows/parity-wave.js` is the saved workflow every later wave starts from (`docs/parity/WAVES.md`).

Date: 2026-10-03

Asked for by the owner as wave 0 of the plan to Shopify parity (`docs/parity-plan.md`). The first report's headline was typed by hand and could not be re-checked; now it is computed, so a wave's claim is a row passing its criteria.
The re-read moved the headline from 59.5% to 57.4% core (must-have 69.0%): 27 rating moves on core rows (D152 and D153 raised five, thirteen or more fell where the code did not hold the row's own criteria, such as search merchandising, segments, the workflow builder, store credit, guest-checkout settings and PCI scope), and the de-duplication. 35 rows that rested on memory were read from Shopify's pages; one still is not (it is listed).
Weights are judgement and were not changed while ratings were. Nothing in this decision changes what stores or shoppers see.
