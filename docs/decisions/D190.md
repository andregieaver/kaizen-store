# D190: Row width in the theme's Row

**Row width in the theme's Row.** The Theme tab's Row section has *Row width* (the content's width or the whole screen's) and *Content width* (what a full-width row holds), as a row's own settings do; every row takes them unless it chooses its own, which wins (also the content's width over a theme that spans the screen).
`ThemeElement.width` and `contentWidth` are laid under rows by `layerUnder()`; a row's fields show what the row comes to and write its own only where that is not what it would be without it (`rowWidthPatch()`).
