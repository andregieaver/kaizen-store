# D597: The admin redesigned, round 2

**The admin redesigned, round 2: lists and a hub (`docs/audits/admin-redesign-round-2.md`; 14 November 2026).** The orders list opens on *To send* while orders wait (All at `?show=all`), with *Start packing* as its one green button, a *More* menu, the views as a pill with To send's count and *More views*, and rows with initials, product pictures and the sending state as a chip (`toSendSummary()`, `orderPreviews()`).
The products list is pictures by default with the table one press away, a search over names and SKUs, filters (On sale, Drafts, Needs stock) and stock as a bar with words (`ProductCatalogue`, `productSkus()`). The product editor shows the VAT part under each price, one fewer / one more beside stock and *Jump to* links in More options.
Settings is by job, each card with its state from the store's setup, a strip of the essentials with the next fix as the green button, and every other setting by name (`SettingsHub`, `teamSize()`); Kaizena Flow's own Settings uses the same hub.
