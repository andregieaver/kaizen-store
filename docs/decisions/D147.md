# D147: The store and the owner's level get the platform's navigation

**The store and the owner's level get the platform's navigation** (D144). A store's admin has the whole width, tabs with icons (Home, Orders, Products, Customers, Marketing, Website, Bookings when on, Settings) and a sidebar for each section; the AI manager tab is gone (it is in the header), Billing, Team, Search, the Chat agent and the AI settings are in Settings, Design is the Website's.
Website and Settings open on pages of cards (`/admin/{store}/website`, `/settings`), Settings' under headings. Sections are data (`src/lib/store-nav.ts`), tested against the folders of the store's admin and the admin map, whose `group` is now the page's section. The owner's level (`src/lib/owner-nav.ts`) has Home, Stores, Work and Account, with Billing, AI usage and Referrals as Account's sidebar. Page wrappers of `max-w-2xl`…`5xl` are removed so pages use the width.
A tab that is exact (a page of cards) still marks the pages listed as its own (`also`), and not those below its address.
