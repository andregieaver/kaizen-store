# D32: Shoppers can create an account with a password, on My account or at checkout; an email the store already knows chooses a new password instead

**Shoppers can create an account with a password, on My account or at checkout; an email the store already knows chooses a new password instead. Emails go through Resend.** My account has two tabs, Sign in and Create account (name, email, password of at least 12 characters); a new account is signed in at once and gets a welcome email.
At checkout, shoppers who are not signed in can tick Create an account and choose a password; it is kept (hashed) with the unpaid order, and the account opens when the order is paid, with the email, name and address they paid with, and that order.
If the email already has an account, or paid orders, no account is made: the shopper is asked to choose a new password, which takes a six-digit code emailed to that address (the same rules as sign-in codes); the code proves the inbox is theirs, so all the email's orders then join the account and every other session ends. At checkout this is said on the order page, with the code form right there.
An account made with a password starts with its email unproven: only orders placed while signed in join it, until the customer signs in with a code or chooses a new password, so registering someone else's email shows nothing of theirs.
Emails are sent with Resend's API from a domain verified in Resend's EU region (Ireland), with each email's id in Kaizen as the idempotency key, so a retry never sends twice; a busy or failing Resend is tried again briefly, and anything else is marked failed in the email log. Resend reports deliveries, bounces and spam complaints to a signed webhook, and the email log shows them.

Date: 2026-09-24

Chosen by the owner for the easiest setup, price and API (Amazon SES, first planned in D26, was never configured and is removed). Resend is a US company: allowed by D10 with its DPA and standard contractual clauses; see the residency register. Saying that an email has shopped before tells whoever types it that the address has been used in the store; the owner asked for it, as larger shops do. Registering is not rate-limited per visitor yet.
A password chosen at checkout is dropped once the order is paid, whatever the outcome. The order page signs the new account in once, within an hour of payment.
