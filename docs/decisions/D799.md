# D799: No English catalogue in the admin's client code

**No English catalogue in the admin's client code (bloat review step 2.26; 19 November 2026).** Admin client code takes its words
as arguments from its page or through `useAdminText()`; no helper defaults to an English catalogue. English constants and the
matching of English sentences live in `-english` modules that only the server imports, and where the server writes an English
sentence it turns it into the account's language before it reaches the browser (`answer-words.ts` beside the actions of A/B
tests and redirects). The import walk in `src/components/admin/admin-bundle.scan.test.ts` lists every client path to an area's
catalogue and the list only shrinks: it went from 35 sites to none, and `admin-catalogues.scan.test.ts` allows only
`admin-text.tsx` and `admin-text-context.tsx` (common and sign-in). Measured on a local build: 83 admin routes fell, 4.86 MB in
all (Work 54 KB each), the five main screens at 634 to 664 KB (ceiling 680,000), the admin's median 643,240 bytes, and the
builder's English in no route (26 before); the bundle budget was lowered with them (589fb73de). Commits aaa201926, 96df64c41,
8cf2b4cc4, 17cdaaf6b, 9e1abf53c, 589fb73de.
