# D249: The theme store, step 3

**The theme store, step 3: its own address (`docs/theme-phase-3.md`).** With `NEXT_PUBLIC_THEMES_HOST` set (`themes.kaizenaflow.com`), the host serves the theme store at its root (`/` the list, `/{slug}` a theme, its own `sitemap.xml` and `robots.txt`) by host routing built with the stores' (`themeHostRoutes()`), Kaizena Flow's `/themes` and `/themes/{slug}` move there (308), and any other address on the host goes to Kaizena Flow's site; `/themes/{slug}/try` stays on Kaizena Flow's host, which
sees the admin's sign-in. The host is never a store's, even as a name under the store domain: the stores' host pattern leaves it out, `storeOfHost()` returns none, and `themes` is a reserved store address. Links in the theme store follow the host (`themeStorePath()`, `themeStoreUrl()`, `platformHref()`); Kaizena Flow's own sitemap leaves the theme store to the host's. Nothing changes until the setting is made.
