# D394: A code editor for owners' own CSS

**A code editor for owners' own CSS (the owner's request of 29 October 2026).** The page builder's Custom CSS panel (D100, both tabs) is CodeMirror 6 (`src/components/admin/css-code-editor.tsx`, the packages pinned to releases at least two weeks old, one copy each): CSS highlighted in the admin's colour roles (so it follows the scheme in light and dark), line numbers, brackets closed and matched, Tab indenting (Escape, then Tab, leaves the editor, and Escape inside it no longer closes the
panel), and suggestions as one types: CSS's own properties, values, at-rules and pseudo-classes, the theme's variables after `var(` (`THEME_VARIABLES`, held to what `themeCss()` writes) and, after a `.`, the classes given to the page's parts and the site's text styles (`knownClassNames()`, `src/lib/css-completions.ts`).
It is loaded only when the panel opens (`next/dynamic`), the plain field drawn until it arrives and if it cannot; its length is held to `CSS_MAX`, and the text is still only checked by `cssProblem()` and drawn by `<CustomCss>`/`<ScopedCss>`.
`e2e/signed-in/css-editor.spec.ts` holds it. **Course change (the owner's request the same day).** The live site's *Custom CSS* (D306) uses the same editor, fetched only when signed-in staff open the panel (visitors never load it), its colours falling back to the site's own theme colours where the admin's roles are not set.
That panel floats at `z-[200]`, above the site's header, the chat (`z-[90]`) and the cart's drawer: on a computer it is moved by its title bar and resized from any edge or corner (`movedBox()`, `resizedBox()`, `fitBox()` in `src/lib/panel-box.ts`; its grip button moves it with the arrow keys and resizes it with Shift, Home and a double press on the title bar put it back), where it was left kept in this browser (`kaizen_site_css_panel`); on a phone it stays a sheet at the bottom.
The builder's panel is made wider or narrower by its left edge (`builderPanelWidth()`, a separator with the arrow keys, a double press for its usual 448 px), kept as `kaizen_admin_builder_css_width`. Both keys are in `KNOWN_COOKIES` (`staff: true`).
