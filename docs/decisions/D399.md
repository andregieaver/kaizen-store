# D399: Checkout rules that reorder, and rules through the API

**Checkout rules that reorder, and rules through the API (wave 12 unit E, `docs/wave-12-after-the-core.md` E): built.** A rule's effect may be `order_delivery` (`RuleEffect`, `EFFECT_KINDS`, the schema, the `checkout_rules_effect` check): the options it names are shown first, in its order, the rest after in their own (`orderedBy()` in `rulesOnOffer()`, for what ships and the pickup places); the first ordering rule stands, one naming an option gone is skipped as any rule is, and the default is
left as it was (the first in the store's own order), so a rule that orders never chooses another option or price for the shopper; `cartSummary()` and `placeOrder()` agree as before (`checkout-rules.int.test.ts`). The Shipping page offers it (*Show delivery options first*, ticked in order).

(`admin-api.int.test.ts`). Migration `20261029170828_checkout_rules_order` (applied by CI, run 737; advisors INFO only).
