# D184: Window rows and a footer revealed on scroll

**Window rows and a footer revealed on scroll.** A row's picture, video or gradient background can be fixed to the screen (`backgroundFixed`), a row takes a height in per cent of the screen's (`height`, per size), and a footer can be fixed so the page's end lifts off it (`footerReveal`). `docs/theme-elements.md` (last section).
