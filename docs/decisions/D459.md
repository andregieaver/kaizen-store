# D459: DHL Paket, nShift, PostNord's booking, and what the carriers do after the booking

**DHL Paket, nShift, PostNord's booking, and what the carriers do after the booking (5 November 2026, `src/lib/{dhl-paket,nshift,postnord}.ts`, `src/server/carriers/{dhl-paket,nshift,postnord}.ts`, `src/server/carrier-cancel.ts`, `src/lib/carrier-collection.ts`, `src/lib/return-services.ts`).** Built like D458, each from the carrier's own published documents. **DHL Paket** (Parcel DE Shipping 2.2.0, Returns 1.1.0, Pickup 1.0.3, Location Finder and Unified Tracking): an OAuth password grant with
the app's key and secret and the Business Customer Portal user, parcels from Germany (Paket, Kleinpaket, and to a post office or Paketshop by its retail id; Packstation left out as it needs the shopper's Postnummer) at prices the store enters, customs lines abroad, the label in the answer kept (fetchable again only before the day's closing), cancelling, DHL Retoure return labels, a collection, and Unified Tracking's status codes (verified). **nShift** (nShift Delivery's REST API, formerly
Unifaun Online): the store's own delivery checkout at checkout, each option named by nShift's service code with its own pickup points (`ShippingOption.pickupPoints`; switching on `checkout` offers the whole checkout, its prices hold VAT), bookings with the sender's quick id, labels made again when printed, collections, cancelling and nShift's statuses (verified); its return labels are built but not offered until a test account confirms the return's parties. **PostNord** books and gets its label
in one call (`/rest/shipment/v3/edi/labels/pdf`, from PostNord's public Postman collection), kept as it cannot be fetched again; CN23 customs lines; Return Drop Off (24) return labels; a collection from Sweden, Denmark or Finland.
PostNord's own examples name 19 MyPack Collect and 17 MyPack Home, which D136 had swapped: the services are corrected and the migration swaps 17 and 19 in a store's saved services and prices (none had PostNord on). **After the booking**, for every carrier that can: a collection asked for from the booking box when the carrier page has *Collection hours* (`collectionFor()`: today with two hours left, else the next weekday; `BookingRequest.collection`, `BookingResult.collection`; UPS's Pickup API,
DHL Express's `pickup`, DHL Paket's, PostNord's, nShift's); undoing a parcel cancels it at the carrier (`ShippingCarrierAdapter.cancel`, `cancelAtCarrier()`: UPS's void, DHL Paket, nShift; DHL Express and PostNord have no cancel call, Instabee's is for home delivery only); return labels per carrier (`RETURN_SERVICES`: Bring, PostNord, Instabox's locker return, UPS's print return label, DHL Retoure), a label given only in the answer kept with the return (`carrier_labels.return_id`).
Also from D458's list: DHL Express to a ServicePoint (MyDHL's service point locator and `onDemandDelivery`), Instabox home delivery. `bookCarrierDelivery()` books PostNord, DHL Paket and nShift too (staff choose a door service on a flat-rate order; for nShift the service code on its page). The comparison page's *Where Shopify is the better fit* line on labels is reworded and saved as a draft (`docs/comparison-pages.md`).
