# D698: Themes, packs and the seed write today's page shape

**Themes, packs and the seed write today's page shape (bloat review step 0.46; 16 November 2026).** The signature themes (Kit, Atelier, Meridian, Kinetic), the content packs and `supabase/seed.sql` write a product grid's columns as today's stored shape (a number for the desktop, the smaller sizes under `at`), where they wrote the old per-size object that only the parse turned into it.
`src/lib/page-shapes.test.ts` parses every page they make and fails when one differs from its parse (with the old shape back, four cases fail). The grids draw the same columns as before (2 on a phone, 3 on a tablet, 4 on a computer; checked on the demo store live). Pages already stored keep their shape until step 3.17. Kaizena Flow's own site is built from the same themes. Commit 88320369.
