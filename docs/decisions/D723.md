The code ratchet holds two counts that only fall: source files over 100 KB (17 today) and over 2,000 lines (12 today), above the brief's 15 and 11 since main grew; `node scripts/ratchet.mjs` lowers them. Commits f7bbeaf9, a0c1757f.
