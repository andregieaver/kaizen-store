# D531: Radial blur, a gradient that spreads from a point the owner places

**Radial blur, a gradient that spreads from a point the owner places (10 November 2026, `GRADIENT_STYLES.radial` in `src/lib/motion.ts`, `GradientBackground.focus`, `setGradientFocus()` in `src/lib/motion-edit.ts`, `FocusFields` in `src/components/admin/gradient-fields.tsx`, `[data-fx-grad="radial"]` in `src/app/motion.css`).** A fifth style for a row's or column's gradient background: its two to four colours spread in soft rings from a focal point, the first at the point and the last at the
farthest corner, mixed in Oklab where the browser can (behind `@supports`, as a declaration holding `var()` that a browser cannot draw is dropped rather than passed over).
The point is `focus: { x, y }` in whole percent across and down the part, the centre when left out, so a gradient saved before reads as it did; a style without a point loses it when the style changes. **Editing:** Homer presses or drags in a small picture of the gradient to place the point; two sliders, *Across* and *Down*, set the same point from the keyboard, and *Centre it* takes it back. **Motion:** its flow is a slow breathing that grows from the point itself (`transform-origin` there), so
the point stays where it was placed; *Still* and "reduce motion" hold it. **Saved gradients** (D183) keep the point, and a saved radial blur's swatch is drawn from it. **The platform:** Kaizena Flow's own pages use the same builder and renderer, so it has it in the same change. No migration (pages and themes are JSON checked by zod).

Date: 2026-11-10

The owner: *add radial blur as an option, with the ability to place the focal point anywhere in the row or column*.
