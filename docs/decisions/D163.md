# D163: A model that sees pictures, chosen and checked in the AI settings

**A model that sees pictures, chosen and checked in the AI settings.** Pictures go to the AI in two places (copying another site's page, `src/server/replicate.ts`, and writing alt texts, `src/server/alt-texts.ts`), and until now both used the one text model, which may not see; the owner had no way to know, and a copy then "corrected by measuring only".
`ai_providers.vision_model` (same provider and key as the text model; empty = the text model) is a field of its own in the form, `/admin/platform/ai` and `/admin/{store}/settings/ai`: the provider's models that usually see pictures are one press each (`visionModels` in `src/lib/ai-provider.ts`, with what each is good for), any name can be typed, and *Check that it sees pictures* sends the model a small picture of two coloured bands (random colours, `src/lib/ai-vision.ts`,
`src/server/ai-vision.ts`) and asks which colours they are, so a text-only model that refuses, or only guesses, is found out (one in twelve guesses right) before anything relies on it. Everything that sends a picture goes through `seeing(connection)`, which swaps the vision model in as the text model; the connection itself keeps the quick text model for searches.
Both settings pages and the page copier's panel say plainly whether a model that sees pictures is set up and link to the field (`#vision`). The list of suggested models is a start, never a claim: the check is the authority.
