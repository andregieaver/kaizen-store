# D183: Saved colours and gradients, text gradients, gradient overlay and pixel sliders in the page builder

**Saved colours and gradients, text gradients, gradient overlay and pixel sliders in the page builder.** `docs/theme-elements.md` (last section). A store's saved colours and gradients are `ThemeSettings.library` (`colourLibrarySchema`), offered in every colour field and gradient editor and **copied** into a part when used (never referenced), kept by `saveLibraryAction` without touching the rest of the theme.
A text can be filled with a gradient (`Typography.gradient`, per kind of text and screen size). A gradient background takes an opacity and a colour overlay. Every pixel field has a slider with its value over the thumb (`PixelRange`).

Date: 2026-10-09

Asked for by the owner; copying chosen over a shared swatch that updates everywhere. No migration (theme and page content are JSON). The page checker does not read gradients' contrast.
