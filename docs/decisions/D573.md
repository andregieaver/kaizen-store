# D573: The phone menu shows the header's menu, a button chooses its own, and sits left or right; the builder's bar folds on phones

**The phone menu shows the header's menu, a button chooses its own, and sits left or right; the builder's bar folds on phones (11 November 2026, `phoneMenuIds()` in `src/lib/site-layout.ts`, `StoreMenu`, `PlatformMenu`, `MobileMenu`, `part-css.ts`, `page-editor.tsx`).** The phone menu listed only the site's header menu (`stores.header_menu_id`), which a header built in the page builder does not set: it chooses its menu with a Menu component, so its phone menu showed only the languages (seen on a
live store). It now shows the menu the button chooses (`MenuDrawer.menuId`), else the header's first Menu component's, else the site's header menu; each menu a button chooses is drawn hidden in the menu and shown when that button opens it (`data-menu-nav`). The button's Position (Style) puts it at the left, middle or right of its column (order and an auto margin; text alignment cannot move a button).
On a phone the page editor's bar shows only Save, Publish, undo and redo, with More for the rest, so the page being edited has the room. Kaizena Flow's site has the same menu and button. No migration.
