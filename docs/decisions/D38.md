# D38: Discount codes can be applied right in the checkout, in stores and on the platform

**Discount codes can be applied right in the checkout, in stores and on the platform.** In a store, the checkout's order summary has a field "Have a discount code?" (and the code in use, with a way to take it off).
The code is checked against the order waiting for payment before anything changes: one that does not apply says why (unknown, expired, used up, below its minimum, not for these items) and the checkout stays as it was; one that applies goes on the cart and the order is placed again at the new price at once, keeping the shopper's consent to downloads. An order that starts a subscription is placed again only after the shopper agrees to its new renewal price, as when the cart changes.
The cart keeps its own field. On the platform, the code field sits with the plans to choose from, and each plan shows what it costs with a code waiting for it and for how long; without a code saved, Stripe's payment page has its own field for Kaizen's codes, and a code typed there is recognised by its Stripe promotion code and recorded on the store's plan like any other.

Date: 2026-09-25

Asked for by the owner. Stripe checks a code typed on its page by the same rules (on, not expired, uses left, the plan's currency) as Kaizen.
