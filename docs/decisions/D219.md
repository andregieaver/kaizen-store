# D219: A store's admin is drawn in the `rail` layout

**A store's admin is drawn in the `rail` layout (`docs/admin-style.md` section 6, step 3).** Layouts are a registry (`src/lib/admin-layouts.ts`: `ADMIN_LAYOUTS` with the regions each draws, `LEVEL_LAYOUTS` per level) read by `AdminFrame`'s `layout`, which renders only the layout's regions, so the sections are never in the page twice (the rail or the tabs).
In `rail`: `AdminRail` (80 px, the darkest surface) holds the logo (to `/admin`) and the store's sections as 44 px icon tiles, each named for screen readers (with what waits on it, "Support, 3 waiting") and shown by name under the pointer or the keyboard, the section being viewed the brand's tile, Settings at the foot (`foot`, set by `storeTabs()`); the top bar has no background or line and holds the switcher, the actions and the account; a section with pages of its own keeps its sidebar beside
the rail. Under `md` there is no rail and phones keep the slide-out menu; under `lg` (no sidebar) the menu button stays for a section's pages. The platform, the owner's level and hosting stay `classic` for now. The four e2e checks that held D149's indigo now hold meadow.
