# D333: The AI manager sends at most 120 tools a round

**The AI manager sends at most 120 tools a round (`src/lib/tool-budget.ts`).** OpenAI-compatible APIs refuse more than 128 tools in a request; an owner with most features on is offered about 190 store tools and the manager's 24, so the AI manager's turns and the agents' safety eval failed on such models ("Invalid 'tools': array too long").
`chooseTools()` keeps the manager's own and sends, in order, the core tools (`CORE_TOOLS`), the tools used earlier in the conversation, the areas the model asked for, the area of the page the person is on and then the other areas, cut at `TOOLS_PER_TURN`; what is held back is named by area in the description of `load_tools`, which loads an area's tools for the next steps of the turn. Roles and features still decide what is offered (`offeredTools()`); an autopilot step's few tools are unchanged.
The eval offers each case its scripted, forbidden and required tools' areas as a real turn would, and its prompt-extraction case no longer counts "Only help with" as a leak (the prompt tells the model to say it).

The owner ran *Check the assistants' safety* on Platform → AI and 7 of 13 cases failed with the tool error.
