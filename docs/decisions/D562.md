# D562: A drop-shipping supplier's return address in parts, and return labels to the return's own address

**A drop-shipping supplier's return address in parts, and return labels to the return's own address (11 November 2026, `supplierInput` and `readReturnTo()` in `src/lib/drop-shipping.ts`, `supplierReturnAddress()` in `src/server/withdrawals.ts`, `load()` in `src/server/return-labels.ts`).** The owner asked that the return label go to the supplier, which D556 had left to the store (a supplier's free-text address cannot be put on a carrier's label).
A supplier's return address is now asked in its parts (name on the parcel, street, postal code, city, country), kept as `suppliers.return_to` (jsonb), all five or none (half an address is refused in words); the old text column `return_address` is no longer written (no production supplier had one) and can be dropped in a later change.
A return whose every line that supplier sent carries its address as before (D556), now whole, and a return label (D239) is booked to **the return's own address** when it is whole, so to the supplier's, or one staff gave the return, falling back to the store's return address as before (an address in parts that is not whole, such as D556's free text, is never sent to a carrier). Store-only, as D550.
Tests: `supplier-orders.int.test.ts` (the parts, refused when half), `return-labels.int.test.ts` (booked to the return's address, the store's when the return's is not whole).
