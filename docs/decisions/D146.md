# D146: Pictures, speech and live calls are priced too

**Pictures, speech and live calls are priced too** (extends D145, which priced tokens only). `commerce.ai_model_prices` gains `per_image` (US dollars per picture), `per_audio_minute` (speech to text and live voice calls, by the call's seconds) and `per_million_characters` (text to speech), each null for "no price" and 0 for free; the price form leaves them empty when a model has none.
A call's cost is its tokens plus its units at those prices, worked out once in `src/server/ai-price-sql.ts` (`priceFor`, `costMicrosSql`, `unpricedSql`, shared by the usage reports, the unpriced list and the recommendations' monthly figure) and in code by `callCost()` (`src/lib/ai-cost.ts`), which a test holds to the SQL.
A call that made pictures, listened or spoke is unpriced when its model has no price or none for that unit, and shows "No price" with a "+" on the totals; a call that reported tokens is priced by them, so a model billed in tokens for its pictures or audio needs no unit price (and should have none, which would count twice). The prices page lists models unpriced for any of this.
