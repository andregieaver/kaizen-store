# D167: Plain text fields of page blocks may hold a small set of inline tags

**Plain text fields of page blocks may hold a small set of inline tags.** A heading, a button's words, a caption, tab and question titles, an icon list's lines, testimonials' quotes, a form's button and success text and a custom grid item's title, price and button are read by `parseInline()` (`src/lib/inline-text.ts`) into `span` (a class), `strong`, `b`, `em`, `i`, `u`, `s`, `mark`, `small`, `sub`, `sup`, `br` and, where a link may be, `a`, and drawn as React elements by `<Inline>`, never as
HTML. Anything else stays the text typed; a class is a plain name; a link passes `isSafeAddress()`. The words alone (`inlinePlain()`) go to search, excerpts, `aria-label`s, FAQ structured data and the accessibility checks.

Date: 2026-10-05

Asked for by the owner (`<span class="highlight-color">.</span>` in a heading, styled by the page's own CSS). The AI translator sees the raw string, so a mangled tag shows as text, never breaks the page.
