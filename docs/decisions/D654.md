# D654: Picture, alt-text and product upkeep cost one statement when nothing changed

**Picture, alt-text and product upkeep cost one statement when nothing changed (bloat review step 0.28; 16 November 2026).** The alt-text job lists a site only while a picture is due (`sitesDueForAltText()`) and gives up on a picture after five failed tries (`media.alt_tries`, cleared by a success; a person's own run still tries it). The picture index lists only sites with a stale picture and checks where pictures are used weekly, not daily.
Every product saver (the editor, translations, bulk edits, imports, copies, the AI manager's product tools, content packs) embeds at once, and the platform-wide product scan runs hourly as a net. `product_translations.text_changed_at` is set by a BEFORE UPDATE trigger only when the title, description or safety information change (on the row itself, never on products, which would queue a product.updated event), for step 0.29.
A test holds an idle run of the AI upkeep jobs to three statements with one site and with twenty. Kaizena Flow's own library and pages are covered the same way.
