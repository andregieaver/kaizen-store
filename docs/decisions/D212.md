# D212: A visitor's browser gets only the interface text its client components read

**A visitor's browser gets only the interface text its client components read (`docs/performance.md`).** The four hand-written languages were one 270 KB module that every visitor's browser loaded. Each is now `src/lib/messages/{lang}.ts` (all read by `t()` on the server and in the admin), spreading in `{lang}-browser.ts` (the texts visitors' client components read through `browserText()`, about 4 KB) and `{lang}-returns.ts` (the withdrawal function's, `returnsText()`, loaded only on its page).
A first version loaded only the page's language as a script of its own and made the page wait for it before waking up; presses in that moment were lost (a gallery's arrows in CI), so the small texts load with the page instead. Held by `storefront-bundle.scan.test.ts`; the demo front page's scripts went from 266 KB to 206 KB compressed.
