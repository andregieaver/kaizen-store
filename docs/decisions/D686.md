# D686: A/B tests

**A/B tests: a version's changes saved but not published are asked to be published (16 November 2026, `src/server/experiment-admin.ts`, `src/components/admin/experiment-controls.tsx`).** Visitors are shown a version's published copy, so a version changed in the builder and saved without Publish read as *still the same as the original: change it first*, which sent the owner to change what they had changed.
Each version now carries `unpublished` (its draft's rows differ from its published copy's); the draft's checklist says its latest changes are saved but not published, its main button reads *Publish Version B's changes* and opens the builder, the version's line says so in place of *Nothing differs*, and `checkStart()` refuses the start with that reason (in Norwegian too) until they are published, so a test never starts on a stale copy.
The side-by-side frames (D684) go on showing a draft test's versions as their drafts, and such a frame is labelled *Draft: not published yet, so visitors would not see this*. No migration, no tool change.
