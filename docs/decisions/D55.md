# D55: One page, its texts in each of the store's languages

**One page, its texts in each of the store's languages.** A page is built once, in the store's main language (its own country's market's); each other language the store sells in keeps only the texts that differ, by their place on the page (`translations` in the page's content: the title, search texts, picture descriptions, each block's text, button and caption, a grid's own texts, a column link's description), so rows, pictures and settings stay one.
The editor has a language choice with each language's progress; in another language the builder shows the page as it reads there, hides everything but the texts, and each part's dialog shows its texts beside the main language's. A text not translated shows in the main language. The storefront, its menus and grids of pages read a page in the market's language (`localizePage()`); a page has one address in all languages.
Saving keeps only the store's other languages and texts the page still has (`cleanTranslations()`); Kaizen's pages are in English only.

Date: 2026-09-25

Chosen by the owner over a page per language. The seeded demo's Om oss page has Swedish texts; in Danish it reads in Norwegian.
