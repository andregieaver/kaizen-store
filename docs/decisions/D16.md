# D16: Checkout on Stripe's hosted page, with each store's own Stripe account

**Checkout on Stripe's hosted page, with each store's own Stripe account.** Kaizen places the order and holds the stock, then hands over to Stripe Checkout; a webhook (created automatically in the owner's Stripe account when they save their secret key) confirms payment.

Date: 2026-09-24

Card data never touches Kaizen (PCI DSS SAQ A). Orders are numbered per store from 1001. Stock is held for 35 minutes (the session's 30 plus a margin). VAT shown on orders uses each country's standard rate until Stripe Tax is connected; reduced rates are not applied yet (see R6).
