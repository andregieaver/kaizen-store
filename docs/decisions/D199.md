# D199: An icon list's icons can take a gradient

**An icon list's icons can take a gradient.** Beside the icon colour, the Style tab has *Gradient icons*: two to four colours at an angle, with the store's saved gradients to start from, as gradient text has (D183). The gradient wins over the colour; the icons' strokes are filled with an SVG gradient defined once beside them.
