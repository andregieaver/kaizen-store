# D46: Rows, columns and components can be saved and used again

**Rows, columns and components can be saved and used again.** Each settings dialog (the wrench on a row, a column or a component) has Save as…, which asks for a name and saves a copy under Saved, the builder's third tab (renamed from Sections).
Saved lists rows, columns and components by kind; each is dragged onto the page (a row between rows, a column beside another column or onto a row, the columns then dividing the row evenly, or last as a row of its own; a component into a column) or pressed to open it: its name and content can be changed (a row's layout and text, a column's texts, a component's text), it can be added to the page from there (without a mouse), or deleted. Using a saved part puts a copy with new ids on the page.
Kept in `commerce.saved_parts` (`store_id` null for Kaizen's own; stores will get theirs), checked like page content, at most 200.
