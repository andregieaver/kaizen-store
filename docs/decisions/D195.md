# D195: The Theme tab reaches the site as it does the canvas

**The Theme tab reaches the site as it does the canvas.** Saving or publishing a page now also keeps any change made in the page builder's Theme tab (before, only the tab's own *Save theme* did, so a size set there showed on the canvas and not on the site). A list's text now wins over the paragraph's inside list items, whose items each hold a paragraph. Leaving with a theme change not kept asks first.

Date: 2026-10-10

Reported by the owner (the paragraph size showed in the builder, not on the site). No migration. `e2e/theme-elements-live.spec.ts` holds paragraph, heading, list and button size, row spacing, content width and body background on the site.
