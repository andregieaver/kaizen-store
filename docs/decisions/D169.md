# D169: A WordPress plugin shows an owner's products with saved shortcodes

**A WordPress plugin shows an owner's products with saved shortcodes (outside the parity waves).** `wordpress-plugin/kaizen-store/` (installable zip at `public/downloads/kaizen-store-wordpress.zip`, built by `scripts/build-wordpress-plugin.mjs`, offered at `/admin/account/wordpress`) connects a WordPress site to the owner's stores by an approval in Kaizen's admin (`/admin/account/wordpress/connect`: the site is named, the return address must be on its own origin, the password never reaches
WordPress) and a one-time code swapped for a token with a PKCE-style verifier; the token (`kzwp_`, kept only as a hash in `commerce.wordpress_connections`, revocable from either side) reads the public catalogue of the stores the account belongs to through `/api/wordpress/v1` (stores with markets, categories and tags, products to pick, and a view of products priced and worded as the storefront does) and nothing else.
In WordPress a *view* (a private post type) holds the store, market, source (all, categories, tags, or products picked by hand in order), count, grid or carousel and columns, is edited with a live preview, and is used as `[kaizen_products id="123"]`; answers are cached ten minutes, the last good one shown only while Kaizen cannot be reached. `docs/wordpress-plugin.md` is the contract.

pages and checked as an article's. 1.0.0 connects to the platform's earlier address by default, which the table says how to set. `wordpress-plugin.test.ts` holds the list, the files and the table together.
