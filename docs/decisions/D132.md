# D132: A plan comparison

**A plan comparison: every feature in a table, the plans as columns, a box for what each includes** (`src/lib/plan-features.ts`, `src/server/plan-features.ts`, `commerce.plan_features` and `plan_feature_grants`). Platform admins edit it at `/admin/platform/plans/features`: one form saves the whole matrix in a transaction (a feature's name, description, category and place, new features, removal, and a tick per active plan; a plan not shown keeps what it had).
It starts with 50 features grouped by category (catalogue, checkout, design, international, AI, operations, Kaizen), in no plan yet, so the admin decides what each plan includes. Store owners see the same table read only under Compare plans on their Billing page, once any feature is ticked. It describes the plans; it does not switch features on or off, so a limit that must be enforced still needs its own check where the feature is used.
