# D125: Saved rows, columns and components can be shared as templates

**Saved rows, columns and components can be shared as templates.** The builder's left sidebar has a Templates tab (replacing Layers) showing the templates the store has switched on, from its owner's other stores or the marketplace, grouped as rows, columns and components; "Browse templates" opens a modal with My stores and Marketplace tabs, kind chips, an "activated only" filter and search, and each template switches on or off.
Saving a part asks who may use it: `commerce.saved_parts.sharing` is `private` (this store, the default), `stores` (other stores the same account **owns**) or `marketplace` (every store owner, live at once); only owners choose. Kaizen's own saved parts are the marketplace's Kaizen listing, on by default until a store switches them off (`template_activations`, `coalesce(active, store_id is null)`).
Using a template is a copy (`applyTemplate()`): `sanitizeTemplate()` strips the source store's links, ids, form recipients, menus, field bindings, personal links and another owner's HTML, and pictures are copied in Storage into the using store's media library (at most 30 files, 80 MB); nothing keeps pointing at the publisher. Visibility is one SQL condition read on every request (a lost ownership takes a `stores` template away at once).
Platform admins hide or show marketplace templates at `/admin/platform/templates`. See `platform.md` (As built: templates).
