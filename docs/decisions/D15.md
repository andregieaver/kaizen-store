# D15: Payment settings belong to the store owner, in the store's admin

**Payment settings belong to the store owner, in the store's admin.** API keys and webhook secrets per payment provider, test or live mode, and an on/off switch per payment method (per market) are edited in store settings, not in Vercel environment variables.

Date: 2026-09-24

Needs an admin area with sign-in (Phase 1c). Secrets are stored encrypted in the database with a key held only in the server environment, never returned to the browser once saved, and every change is logged. The only payment-related environment variable is that encryption key.
