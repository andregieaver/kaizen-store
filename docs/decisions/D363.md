# D363: A custom app's tools for the AI manager

**A custom app's tools for the AI manager (wave 9 unit J, `docs/wave-9-platform.md` section 3, J); built.** Settings → Apps and API gains *Your apps for the AI manager*: an owner connects an app that speaks MCP (`commerce.custom_apps`, at most `APPS_MAX` 5 a store, written only by `src/server/custom-apps.ts`, audited `integration.custom_app_*`, `never` copied): a name, the endpoint (`checkEndpointUrl()`, the events' rules: https on a host name, the standard port, no login) and an optional
bearer token, both encrypted with the settings key and shown back only as the host and the token's last characters.
Its tools are read at once and again on *Read tools again* by a JSON-RPC `initialize` (the `Mcp-Session-Id` it answers kept for the call) and `tools/list` through `safeFetch()` (the replicator's address guard, no redirects, ten seconds, 1 MB), JSON or server-sent events (`readRpcAnswer()`); `readToolList()` keeps at most 50 tools of a name of their own shape, a description cut to 1,000 characters and an object schema under 20 KB, and a tool no longer listed is switched off.
The owner switches each tool off, `read` (runs at once) or behind a gate (`public`, `send`, `spend`).
The AI manager offers the tools switched on (at most `APP_TOOLS_OFFERED` 20, beside its own within `TOOLS_PER_TURN`) to owners only and never in an autopilot step, named `app__{app}__{tool}` (`appToolName()`), described as the owner's own app's words; a gated call is kept as any gated tool is (`keepForApproval()`, its summary naming the app, the tool and its arguments) and run by `decideApproval()` only while the person is still an owner and the tool still on with a gate.
Each call (`callAppTool()`, `tools/call` with the model's arguments as an object) is counted on the app (`calls`, `failed`, `last_called_at`) and logged, and its answer reaches the model as text only (`toolAnswerText()`: other kinds named, cut to 8,000 characters) beside the rule that it is data from outside (`UNTRUSTED_TEXT`).
Calls are counted on the app, not as `custom_app` in `ai_usage` as section 3 said: a tool call has no model, tokens or price, and an unpriced row would stop the autopilot's budget (`aiBudgetProblem()`). `safeFetch()`'s answer now carries the response's headers. `ai.third-party-apps-extend-the-assistant` moves to full. Migration versions: `20261028142058_custom_apps` (applied by CI on 28 October 2026, run 702; advisors to check).
