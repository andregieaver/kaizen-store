# D145: AI usage shows what it costs

**AI usage shows what it costs** (supersedes D106's "money is not shown"). Prices are data, never code: `commerce.ai_model_prices` holds US dollars per million input and output tokens for a provider's model, set at `/admin/platform/ai/prices` (Settings), a price never changing in place (a new price counts from now; a model's first from the beginning, so usage already recorded is priced).
A call is priced by the price in force when it was made, matched on provider and model exactly or as the start of a dated version's name (`matchPrice()` in `src/lib/ai-cost.ts`, `priceFor` in `src/server/ai-usage.ts`); cost is worked out in millionths of a dollar in SQL and code, never by the model.
Every page that shows tokens shows cost beside them: the platform's and an owner's usage reports (totals, per day, per provider and model, per owner account, store and feature), a store's recommendations cap ("used this month"), and the AI manager's usage answers (`estimated_cost_usd`). Models used without a price show "No price", the totals a "+", and the prices page lists them with a link to set one.
The three models the platform already used were priced from their providers' lists when this was added and marked to be checked.
