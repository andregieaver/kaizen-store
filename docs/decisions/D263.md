# D263: The scheduler calls Kaizena Flow's own domain

**The scheduler calls Kaizena Flow's own domain.** Supabase's `pg_cron` jobs (the five-minute job, the cookie scan, the integrations every minute, the daily reminders) called `https://kaizenstore.cloud/api/cron/*`; once that domain redirected to `kaizenaflow.com` (D240), the redirect dropped the Authorization header and every call was refused (401: at least from 09:28 UTC on 16 October 2026, as far back as `net._http_response` keeps).
Migration `cron_host` rewrites each job's address in place (`cron.alter_job()`, name, schedule and body kept); new jobs name `https://kaizenaflow.com`. Work the jobs missed (emails, invoices, retention, theme updates) is picked up by their next runs, as each job takes what is due rather than what is new.

Date: 2026-10-16

Found while adding the theme shots' job: all 792 scheduled calls kept by `pg_net` had answered 401. Migration version (applied by CI, 16 October 2026 15:45 UTC): `20261016152843_cron_host` (data only; calls answer 200 from 15:46).
