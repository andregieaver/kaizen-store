# D214: The page builder's palette follows the store's features, and the canvas draws what the site draws

**The page builder's palette follows the store's features, and the canvas draws what the site draws.** With the online shop off (D178) the palette has no Shop pages section, no pieces of the cart, checkout or order, and no More heading over the rest; a shop component behind no feature (the Cookies page) is among the other components in More, as a website needs it as much as a shop (`builder-palette.test.ts`).
The canvas draws a background fixed to the screen (D184) as a row's ordinary background: its page is a container, which a pinned layer takes as its window, so the picture lay at the top of the canvas and the row's frame cut it away. A part's hover effect (Motion tab) is drawn on the canvas with the motion preview off, as hover timing was (the pointer-following ones still need the preview's runtime).
A button's hover shadow (`shadow`, `lift`, `glow`) is `!important`, so a resting shadow from the button or the theme's Button element no longer hides it, on the site too (`e2e/hover-timing.spec.ts`). The Table tile has a visible picture. No migration.
