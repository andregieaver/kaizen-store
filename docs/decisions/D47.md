# D47: Pictures are a component, and every row, column and component has margin and padding

**Pictures are a component, and every row, column and component has margin and padding.** Components gains Image: a picture (uploaded like product pictures, shrunk to WebP in the browser), its description for people who cannot see it, and an optional caption shown under it. A component without a picture shows a placeholder in the editor and nothing on the site.
Every settings dialog (rich text, image, row, column) has margin (space outside) and padding (space inside) for the top, right, bottom and left, in pixels from 0 to 240; the canvas shows changes at once, and the site uses the same values. Stored in the page's JSON as an optional `style` on the row, column or block, so no migration; sides at 0 are left out, and a saved part keeps its spacing.

Date: 2026-09-25

Asked for by the owner. Pixels rather than a fixed scale, so the settings say exactly what the page gets; the limit of 240 keeps a typo from pushing content off the page. The caption counts as the component's text for the page's excerpt and llms.txt.
