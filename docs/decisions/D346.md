# D346: Asking for figures in words

**Asking for figures in words (wave 8 unit B, `docs/wave-8-analytics-ai.md` section 4, B); built.** The AI manager has three store tools over D345's report layer: `report_catalogue` (the figures, what each means and the cuts it allows, the periods and comparisons, what a filter's values are; `analytics:read`), `run_report` (a `ReportSpec`, checked by `reportSpecSchema` and `specProblems()`, run by `runReport()`, answered as `describeSpec()`'s sentence, the rows with their figures written out by
code in the store's main language and format, the totals, the page's notes and the report's address; `analytics:read`, in `CORE_TOOLS`) and `save_report` (through `saveReport()`, `analytics:write`, answering the saved report's address), in `src/server/report-tools.ts`, none gated (nothing a shopper sees changes), all behind the shop feature.
A spec the catalogue refuses is refused in its words and pointed at `report_catalogue`; the model fills a spec and repeats what comes back (a prompt line for stores, the know-your-customers playbook), never adding, averaging or converting.
A turn that calls `run_report` carries the report's address on its trail (`ToolTrail.report`, read back only in the builder's own shape by `reportOfResult()`, `src/lib/report-link.ts`), and the panel shows *Save as report*, which opens the report where Save keeps it. The rounds after a report tool are metered as the AI feature `analytics_question`. The safety eval gains `manager-report-row` (a product name in a row hides another figure).
The autopilot's reviews may read with `report_catalogue` and `run_report`. No migration.
