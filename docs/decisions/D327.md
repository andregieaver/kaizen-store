# D327: A standard product taxonomy

**A standard product taxonomy (wave 6 unit I, `docs/wave-6-catalogue.md` Unit I); built.** A product may take a category from Shopify's open Standard Product Taxonomy (release `v2026-10`, MIT licence, kept with its notice in `src/data/product-taxonomy/`), apart from the store's own categories and the tax code (`products.standard_category`, Shopify's stable id), with the category's attributes' values (`products.standard_attributes`), checked against the category by `standardProblems()`.
The taxonomy is kept as generated files (structure and names in English, Norwegian, Swedish and Danish, Shopify's own translations), not rows: some 10 MB of SQL a language; a release that retires or moves an id comes with a migration mapping the ids products keep.
The editor searches it; Shopify's CSV `Product Category` is imported and exported; listings filter by attributes; the feeds send Google's category; a model may only suggest a category, which staff accept: code finds at most 25 candidates in the product's own words (`categoryCandidates()`, rarer words weighing more), the model picks one id or none (`readCategoryChoice()`, feature `product_taxonomy`), and the editor shows it with *Use it*.
The AI manager reads it in `get_product` and sets it in `create_product`/`update_product` by id or full English path, attributes by name, resolved by code (`attributesFromNames()`; anything else refused with the closest categories). Migration versions (applied by CI, 27 October 2026 09:35 UTC): `20261027080538_standard_taxonomy`, `20261027080603_standard_taxonomy_sql`. Advisors checked after: no error or warning; INFO only (RLS on, no policy; the two new indexes not yet used).

Date: 2026-10-27

*Why:* `catalogue.standard-product-taxonomy`; feeds carried no `google_product_category` and the attributes Shopify merchants fill had no home. Decision 1 of the wave chose the taxonomy; its licence was read before building. Built in three steps (I1 the data, model and admin, I2 filters, feeds and structured data, I3 the AI's suggestion, the AI manager and the tracker).
