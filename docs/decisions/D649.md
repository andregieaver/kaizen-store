# D649: The knowledge job reads no document when nothing was published

**The knowledge job reads no document when nothing was published (bloat review step 0.27; 16 November 2026).** `commerce.knowledge_sources` keeps one row for each published page, article or entry the chat agent's knowledge cut (its publishing date, address, type version and path), also for a page with no words, so it is not cut again every five minutes.
`syncPageKnowledge()` reads ids, addresses and a stale flag first and fetches a document only for a page whose row is missing or older than its publishing, or whose address or type changed; `sitesWithWork()` asks every site at once, so an idle run is one statement; `refreshKnowledge()` takes a full pass in the first five minutes of each hour as a net. The chat's passages and their paid vectors are cut again only for a changed page.
The fill migration recorded every page whose passages were current, so the first run after the deploy cut nothing again. Kaizena Flow's own site's pages are covered the same way (owner null).
