# D117: The cart, checkout and order pages come apart in the page builder, as a product's page does

**The cart, checkout and order pages come apart in the page builder, as a product's page does.** The whole components (`cart`, `checkout`, `order`) stay for pages that want them; beside them are pieces (`STORE_PIECES` in `src/lib/store-parts.ts`), each a `storePart` block whose `part` names it and whose page is `routeOfPart()`: *cart* items, summary, discount code, checkout button and a way back to the store; *checkout* items, discount code, totals, payment form and a link back to the cart;
*order* thank-you (also refreshing the page while the payment is confirmed), account created, bookings, items, totals, subscription, downloads, delivery address and a way back to the store. A piece draws only on its own page (`StorePartSection`), and a piece with nothing to show (a summary of an empty cart, downloads of an order with none) draws nothing.
Pieces are bare (no frame or heading): the block's spacing, border and shadow settings make them look as the owner likes, and the whole page frames them itself. The pieces of one page read the cart, the checkout or the order once per request (`perRequest()` in `src/server/request-memo.ts`, so the order is not fetched, nor Stripe asked, for each piece) and draw the same functions the whole component does, so the two cannot drift.
Starter pages for the cart, checkout and order are made of pieces laid out as the standard pages are (`starterPage()`); pages already built with a whole component keep working. Roles stay the whole pages (`PAGE_ROLES` follows `STORE_PARTS`, not the pieces). No migration: a piece is a value in the page's JSON.

Date: 2026-09-29

Asked for by the owner: to rearrange these pages in creative ways, and a working page in one piece could only be moved as a whole. Splitting it the same way as the product page (D79) gives the same freedom without a second mechanism: same block, same builder palette, same page rules. A separate block type per page was rejected as three copies of the same plumbing; making pieces roles would have offered "a page for the cart summary".
