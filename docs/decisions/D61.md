# D61: A store's own code, only on its own host and only with consent

**A store's own code, only on its own host and only with consent.** Owners paste code for the page's `<head>` and the start and end of its `<body>` on the Cookies and tracking page (`stores.custom_code`, `src/lib/custom-code.ts`), each with the cookie category it falls under.
Code marked necessary is added as every page starts (`StoreCustomCode`); code in an optional category is added by `ConsentManager` once the shopper allows that category, and its category brings the banner, the cookie page and the scan's consent with it (`siteCookies()`). The code is added in the browser, parsed as a document fragment so its scripts run in order, once per page load; it is never in the server's HTML.
It is only added on the store's own host (P7, `liveCustomCode()`): on Kaizen's shared host it could reach the admin's session, so until the store domain is set it is saved but not added. Owners only, audited with each place's category and length.
