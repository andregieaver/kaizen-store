# D449: Moving from BigCommerce

**Moving from BigCommerce: one button, nothing lost (proposed 3 November 2026, `docs/moving-from-bigcommerce.md`; nothing built).** The move engine of D445 with a BigCommerce reader: a read-only single-click app (or, until BigCommerce approves it, the owner's own store-level API account with read-only scopes), read page by page within the store's shared hourly API limit (a third kept free for the owner's other apps), each item's own `custom_url` and BigCommerce's 301s fed to the address check,
price lists and channels mapped to countries and customer groups, modifiers brought over as choices or left as drafts with the reason, and gift certificates kept **with their own codes** (hashed as ours are, `gift_cards.source` `import`, frozen until Move, no emails). Open for the owner: newsletter consent from BigCommerce's subscriber record (no opt-in level), several storefronts as one shop or several, and shipping with the API token before the app is approved.
