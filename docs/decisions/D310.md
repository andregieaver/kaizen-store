# D310: The agent looks at what it builds

**The agent looks at what it builds (`docs/ai-autopilot.md` unit C, "eyes").** A page's draft (through a signed ten-minute address that opens that draft only) or the store as shoppers see it (home, a product page, the cart) is photographed at a phone's and a computer's width, one browser per width inside `looking()`, measured by code in the page (sideways scrolling, pictures that did not load, no words, no button in the first screen) and judged by the store's model that sees pictures
(`seeing()`, feature `page_look`) against a fixed list of checks, its JSON read by code into findings, with the accessibility checker's blocking issues and claims in the words.
A look is a job (`commerce.page_looks`), run at once by a dedicated route that alone loads Chromium and every minute for what is left; the tools `look_at_page`, `look_at_store` and `get_page_look` are read-only, a page is looked at at most three times an hour, and the autopilot's page check may ask for a look, so a page goes back for one more round at most twice before the owner is asked. Photographs are never kept; findings 30 days.
