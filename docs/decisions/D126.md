# D126: A page can be duplicated

**A page can be duplicated** from the pages list and from the builder's toolbar (pages, articles, product layouts, headers and footers, Kaizen's and stores'). The copy is made by the ordinary `savePage` as an unpublished draft titled "Copy of …" at the first free `-copy`, `-copy-2` … address (`src/lib/page-duplicate.ts`), so it is validated like any page and is never live, a front page or a role's page.
From the builder it copies what the editor holds now, unsaved changes too, without `globalEdits` (a copy never changes a global part for the pages using it) or field entries; a page's or article's custom field values are copied by SQL. Audited as `{store\|platform}.{type}_duplicated`.
