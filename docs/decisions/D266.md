# D266: Any made picture of a theme can be swapped for the platform admin's own

**Any made picture of a theme can be swapped for the platform admin's own (the theme showcase plan, phase 2 step 3, `docs/theme-showcase-phase-2.md`).** The share image and each of the three highlights are slots (`OWN_SLOTS`); a picture put in one (`ThemeListing.own`, an address of this site or https, as a theme's other pictures) is shown in the made one's place everywhere it is read (`sharePicture()`, `themeHighlights()`, which shows a highlight with its own picture even before one is made),
and taking it away shows the made one again. It is saved on its own, at once, by `saveThemeOwnPicture()` (audited `platform.theme_picture_replaced`/`_restored`), so the listing form and the launch themes' sync keep it, and the sync now also keeps a launch theme's main picture, which is the admin's. The card and the first screens were already the theme's own (its main picture, its listing's further pictures), so they are not slots.
The theme's pictures count as uses of Kaizena Flow's library files (`theme_listing` in `mediaUses()`), so the library says where a file is used before it is deleted, and Compress keeps the original and never makes it AVIF, a share image being read by other sites. Homer publishes and never uploads; Lisa opens *Use your own pictures* under *Pictures*.
