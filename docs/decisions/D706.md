# D706: Admin redesign round 32

**Admin redesign round 32: Activity, Analytics and the chat agent on a phone (`docs/audits/admin-redesign-round-32.md`; 17 November 2026, `src/components/admin/activity-view.tsx`, `src/components/admin/phone-more.tsx`, `src/components/admin/analytics/overview-sections.tsx`, `src/components/admin/analytics/kpi-card.tsx`, `src/components/admin/chat-agent-view.tsx`, `src/components/admin/chat-agent-form.tsx`).** The tallest store pages on a phone after round 31.
Below 640 px: the activity log folds a run (changes one after another by the same person, made the same way, in the same area, at most ten minutes apart: `activityRuns()`) into one row naming its kinds of change and how many, which opens to each entry unaltered; the first 20 rows show before *Show 20 more* (`PhoneMore`, its kept-back class in `phone-more-class.ts` so server code reads it as a string).
The analytics overview's four figures share one card two by two (`KpiCard` `phoneCompact`: no trend line or last year's change there), and the steps to see more and the best sellers are rows. The chat agent says first whether it is on and what it needs (*Choose a model*), then the agent, greeting, guidance, voice and daily limit as rows saying what is set, the knowledge base and how it works as rows after them. `PhoneRow` gains `inset` for a row inside a card that has its own padding.
From 640 px each page is as before. The new A/B test's *More goals* link wraps at every width, so that page no longer scrolls sideways on a phone. The platform's activity log and chat agent use the same views and get the same rows; the platform has no shop analytics of this kind.
