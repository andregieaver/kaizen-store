# D181: Addresses without a country for a store that sells in one

**Addresses without a country for a store that sells in one.** `docs/marketless-addresses.md` is the contract. A store that offers one country (Several countries off, or one kept) has no country in its addresses: `kaizenalabs.com/home`, `/s/{store}/home`; a language or currency offered that is not the country's own is a short prefix (`/en/…`, `/eur/…`, `/en-eur/…`).
The routes stay `/s/[store]/[market]/…`: the proxy (`STORE_MATCHER`, now every page path) rewrites a short address to the long one and moves an old long one to the short one (308, path and query kept), and for a store that sells in several moves a short address back (a choice to `/{country}-{choice}/…`, a live page or working route to `/{country}/…`, else D168's manual redirect or the 404 it was), so links keep working both ways.
The decision is pure (`addressDecision()`, `src/lib/store-address.ts`) over the store's shape (`store.address`, `storeAddressOf()`), which the proxy reads at most once per store and instance every 10 s (`FACTS_MS`; the Features, Countries and Localisation saves forget it at once): a switch takes effect without a deployment.
Links follow in one place: `getStore()` notes the shape and `marketPath()` reads it (`marketHome()` where an address cannot be empty); emails' store loader, the sitemap, llms.txt, robots.txt, canonical and hreflang, the pay routes' policy and checks, the visit beacon and the language menu follow. A store's kept languages and currencies are reserved page addresses (`reservedChoiceSlugs()`).

Date: 2026-10-08

Asked for by the owner. No migration (derived from features and markets). Every page request now runs the proxy (a function call, no database call per request) instead of only addresses without a country and A/B visitors; the alternative, routes built into the deployment like P8's domains, would need a deployment for every new store and every switch.
New stores (the shop alone) and stores made in tests without `countries` have short addresses; the demo template sells in three countries and keeps the country.
