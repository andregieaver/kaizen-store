# D628: Watch and roll back the autopilot's changes

**Watch and roll back the autopilot's changes (`docs/100-day-challenge.md` F4; 15 November 2026, `src/lib/autopilot-watch.ts`, `src/server/autopilot-watch.ts`).** Every hour (the dispatcher's job `autopilotWatch`, in each hour's first five minutes) each change the autopilot made itself in the last two days that can be undone (`REVERTIBLE_TOOLS`: prices, a new or switched-on code or campaign, a theme made live, an ad budget) is judged from six hours on: conversion (paid orders per visitor) and
add-to-cart (carts with goods per visitor) since it, against the same hours of the four weeks before together (`baselineWindows()`). Nothing is stored per hour, so the hours are counted from the visits' first seen, the carts' created and the orders' placed times. A fall is clear only with 150 visitors since and 300 before, more than 35 % below expected and three standard errors below (`watchVerdict()`); conversion is read first.
A clear fall undoes the change at once, as the autopilot, from what the change left behind: each price back to its audited before (`product.price_changed`) where it is still what the change made it; the code or campaign switched off; the theme switched back to the install before, while the one it made live still is; the ad budget back to its audited before. Something a person changed since is left alone.
Each verdict is one audit entry (`ai.change_watched`: the change, the verdict in words, what was undone), kept at once for a fall and when the 48 hours end for the rest (fine, too little traffic), and once for a store that counts no visits (not watched). The console shows each challenge store's rollbacks of the last 14 days; every store's activity log shows them.
Course changes: errors are counted per day only (`store_usage_daily`), too coarse to blame one change, so they are not watched; a page published is not rolled back yet (its versions exist, D305, but no restore does), nor a price rule or a broadcast (never automatic). No migration: the verdicts are audit entries.
