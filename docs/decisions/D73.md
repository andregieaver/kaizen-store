# D73: AI providers and models are settings, not code

**AI providers and models are settings, not code: Kaizen chooses one provider for every store at Platform → AI, and a store's owner may choose their own instead.** A provider is Vercel AI Gateway, Mistral AI, OpenAI, Google Gemini or any other OpenAI-compatible API (a public https address), with an API key (encrypted with `SETTINGS_ENCRYPTION_KEY`, never shown again, only its last four characters), a model for search by meaning (embeddings) and a model for text (understanding searches, product
content), either left empty to switch that use off, and the similarity a product needs to be found by meaning. For the gateway, each model can be kept to EU data centres (the request fails rather than run elsewhere) and every request can ask for zero data retention. Kaizen's settings are one row of `commerce.ai_providers` with no store; a store's own row replaces them while on, and switching it off or removing it goes back to Kaizen's.
Features ask `aiFor(storeId)` for the connection and call `embedTexts()` or `completeText()` (`src/server/ai.ts`), plain `fetch` to `/embeddings` and `/chat/completions`, and must keep working without AI when there is none or a call fails. Vectors are kept with the name of the model that made them (`embeddingSpace()`), so a new search model re-embeds rather than mixing.
Only owners choose a store's AI, as it sends the store's products and shoppers' searches to another company; changes are in the audit log. Test, on both pages, tries both models and shows how similar a matching and an unrelated product come out, which is where the limit belongs.

Date: 2026-09-27

Asked for by the owner ("super easy to change AI provider and model later from the platform side, and store owners may override it with their own"). An OpenAI-compatible API instead of a provider SDK keeps every provider one address away and needs no new package; the AI SDK can still be added for the assistant (Phase 3).
No embedding model on the gateway can be pinned to the EU yet (September 2026): Kaizen's planned search model is Mistral's (`mistral/mistral-embed`, served by Mistral from the EU, zero retention), recorded in the residency register. A store's own provider is the store's own processor, under its own agreement. Addresses are limited to public https hosts and redirects are refused, as the server calls them with the key.
