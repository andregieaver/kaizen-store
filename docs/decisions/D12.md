# D12: Kaizen Store is a multi-purpose template

**Kaizen Store is a multi-purpose template**, not tied to one product category.

Date: 2026-09-23

VAT comes from a Stripe Tax code per product (with a per-variant override); every goods withdrawal exclusion is available; producer responsibility schemes are tracked per product with registrations per market; `commerce.missing_registrations` shows the gaps per store. Variants carry a customs tariff (HS) code and country of origin for export declarations.
