# D236: Kaizen's builder offers Kaizen's own templates

**Kaizen's builder offers Kaizen's own templates.** The Templates tab and *Browse templates* in Kaizen's page builder list Kaizen's own saved parts and page layouts (`store_id` null, not hidden), always on and never other stores' marketplace templates: a store's part shared to the marketplace is written for stores, and Kaizen's site is not one.
Using one is `applyKaizenTemplate()`: the part as saved, checked again with `savedPartInput` and audited `platform.template_used`; nothing is copied, as its pictures are already Kaizen's. The preview is `/admin/account/templates/kaizen/{id}/preview` (`templatePreviewPath(null, id)`, platform admins only), drawn in Kaizen's theme, fonts and CSS (D235) and inert like a store's (D127).
The builder's `own` mode hides the source tabs, the on/off switches and sharing (`TemplateActions.previewStore` null).
