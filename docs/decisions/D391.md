# D391: PSI

**PSI: agents and privacy (wave 11 unit L, `docs/wave-11-core-and-psi.md` L): built.** **Prompt versions** (AGT-14): each agent's system prompt is drawn with fixed inputs (Eval Store in Norway, a fixed day, no owner's instructions or memories: `fixedChatPrompt()` and `fixedLegalMessages()` in `src/server/prompt-versions.ts`, `fixedManagerPrompt()` beside `managerPrompt()`) and hashed (`promptHash()`, twelve hex digits of SHA-256), so the version changes only with the prompt's code; the AI
manager's answers keep it (`assistant_messages.prompt_version`), the chat's AI answers keep it in their data (`prompt`, left out of the visitor's feed by `visitorData()`), and every eval run keeps all three (`ai_eval_runs.prompt_versions`, `promptVersions()`). **The evals in CI against a recorded model**: the agents' eval now plays exactly the fixed prompts, and a run against the real model on Platform → AI keeps what the model answered at each step of each case (`ai_eval_runs.recording`,
`EvalRecording`), downloadable there (`/admin/platform/ai/eval/{run}/recording`, platform admins); kept in the repository as `src/data/agent-eval-recording.json`, it is replayed on every push by `agent-eval-replay.int.test.ts` through the same harness (`replayAgentEval()`, no model: a recorded call to a tool no longer offered, or a harness asking more than was recorded, fails the case), which fails when a prompt changed since the recording (`recordingProblems()`), a case was added, or the
recorded model fails a case. **Course change**: the gate is live from the first recording kept in the repository; until then the replay is a stated to-do, never a pass.
A prompt change then needs a new run on Platform → AI and its recording committed. **The DPIA's findings in code** (`docs/dpia-ai.md` R4, R6): the AI manager's conversations are kept 12 months after each message (retention kind `assistant_conversations`, a `policy` row) or the store owner's own period (`stores.assistant_keep_months`, 1 to 60, Settings → AI, written only by `saveAssistantKeep()`, audited `store.assistant_keep`), enforced daily by `runRetention()` through
`pruneAssistantConversations()`: messages and decided approvals older than the period go, then a conversation left empty unless an autopilot plan, a waiting follow-up or a pending approval uses it.
The chat's notice says that an AI reads the tone of the customer's messages and that it summarises the conversation, each only while the desk is on, has it on and has a text model (`ChatWidgetProfile.aiUse`, words `m.chat.aiUse` hand-written in nb, sv, da and en, `HAND_WRITTEN_ONLY`, for legal review); the support settings page tells the owner which of the two are on and that customers are told (`aiOn`, `toldInChat`).
Tests: `agent-eval.int.test.ts` (recording, versions, replay to the same score, a stale prompt and a tool no longer offered named), `assistant-retention.int.test.ts`, `chat-ai-use.int.test.ts`, the replay.
