# D655: The listings' check reads only new or reworded listings, and an unusable answer waits a day

**The listings' check reads only new or reworded listings, and an unusable answer waits a day (bloat review step 0.29; 16 November 2026).** The platform's check of shop listings (D411) picks its candidates every five minutes by `product_translations.text_changed_at` (step 0.28) against `content_screened.screened_at`, without hashing every product's words; an hourly pass compares by hash as the net. A listing whose words' hash is unchanged is stamped without a model call.
An answer that cannot be used is a try (`content_screened.tries`, `tried_at`) and the listing is asked again a day later, instead of at the head of the queue on every run; a provider error records a try and ends the run. Candidates are read before the AI connection, so a run with nothing to check reads none. Prompts and the parsing are unchanged. The check is the platform's own (it reads every store's listings), so nothing else applies.
