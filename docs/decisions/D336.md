# D336: Speed

**Speed (wave 7 unit B, `docs/wave-7-storefront.md` section 4, `docs/analytics.md` Speed); built.** Pictures are offered at the visitor's device size from the two files the library keeps (D213: up to 1600 px and a 480 px copy) as a `srcset` with `sizes` from the listing's, grid's or picture's own width (`pictureSources()`, `gridSizes()`, `fixedSizes()`, drawn by `SizedPicture`); a picture with one file is drawn as before.
The speed report (Analytics → Speed) is field data only: while the store counts visits, `SpeedBeacon` (never on the pay routes, nothing with GPC or Do Not Track, no cookie or identifier) sends one page load's Core Web Vitals to `/api/visit/speed`, kept in `commerce.speed_samples` as the page's kind and the screen only (10,000 a store day, 90 days), and the report gives the 75th percentile per kind and screen over 28 days with Google's ratings, at least 20 page loads a figure.
CI holds page weight, the largest picture and the first byte of the demo store's front and product page (`e2e/performance.spec.ts`).
