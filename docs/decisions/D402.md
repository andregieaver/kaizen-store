# D402: Checkout rules that price a delivery option

**Checkout rules that price a delivery option (wave 13 unit B, `docs/wave-13-loyalty-rules-einvoices.md` B): built.** A rule's effect may be `delivery_price` (`RuleEffect`, `EFFECT_KINDS`, `deliveryPriceSchema`, the `checkout_rules_effect` check): the options it names cost nothing, a percentage more or less (−100 to 300, half up) or an amount more or less in each currency the store shows (an amount in another currency is refused on save; a basket in a currency the rule names none of is
untouched, as a total in another currency never holds).

delivery's as ever. The editor offers it beside the other effects; the Admin API takes it through the same writer. `platform.custom-logic-functions` rated Full. Migration `20261029175737_checkout_rules_delivery_price` (applied by CI, run 739; advisors INFO only).
