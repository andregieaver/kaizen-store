# D98: Saved rows, columns and components can be global

**Saved rows, columns and components can be global: every page using one shows the same, and a change in one place changes it everywhere; inside a global, columns and components can be each page's own.** A global is a saved part with `global` on (`saved_parts.global`, and its texts in the owner's other languages in `saved_parts.translations`, D55).
Pages keep whole copies, so the site, search, forms, the chat's knowledge and translations read pages as before: a use is the global's content marked on its first part with the global's id (`PartBase.global`), and when a global changes the server writes every page using it again, drafts and live versions (`published_at` moves, so the chat's knowledge follows), inside one transaction; a page the change would make one that cannot be saved (`pageInput`, `pageRulesProblem()` in
`src/server/page-rules.ts`) stops it all, naming the page. A use's ids are the global's XOR one mask (`src/lib/part-ids.ts`): each use has ids of its own, the same part has the same place in every use (so translations, kept by place, follow), a global inside another global's use stays one, and the mask applied again gives the global's ids back.
Inside a use, a column or component marked `local` is the page's own: the global keeps its place, each page what is in it (a new use starts from the global's), and changing only what is in it is no change to the global; the mark belongs to the nearest use it is in. Globals hold uses of other globals (a global component in a global row): saved parts follow a change components first, then columns, then rows (`spreadGlobals()`, `src/server/global-parts.ts`).
In the builder (`src/lib/global-parts.ts`, pure and shared with the server): Save as… has a Global box, after which the part is the global's first use with the ids it has (`globalContent()`, `markUse()`); a global from Saved is a new use (`newUse()`); an edit to one use reaches the page's other uses at once (`settleUses()`); a use's settings say whose it is and can Unlink it (a copy of the page's own), and a part inside one has Only on this page; the canvas marks uses violet and the page's own
parts teal. On save the editor names the globals it changed (`globalEdits`, from `editedGlobals()` against the globals as it knows them): only those are taken from the page, and every other use on it is brought up to date, so a page open a while does not undo someone else's change. Changing a global under Saved reaches its pages too; turning Global off or deleting it leaves each page what it has as its own. Kaizen's library gives stores plain copies (D56). Duplicating a use makes another use.

Date: 2026-09-28

Asked for by the owner: global rows, columns and components, where global rows may hold columns and components that are not global. Keeping copies in pages, rather than references resolved when a page is shown, leaves every reader of pages unchanged and the site as fast; the cost is writing every page that uses a global when it changes, which is small for a site's pages.
