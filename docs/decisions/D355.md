# D355: The Admin API with scoped tokens

**The Admin API with scoped tokens (wave 9 unit B, `docs/wave-9-platform.md` section 3, B); built.** An owner makes a token at Settings → Apps and API (`/admin/{store}/settings/api`, owners only): a name and the scopes it may use (`API_SCOPES`: `products`, `inventory`, `orders`, `customers` and `discounts`, each `:read` or `:write`, a write scope also reading), shown once (`kf_` and 32 random bytes) and kept only as its SHA-256 with its first characters (`commerce.api_tokens`, written only by
`src/server/api-tokens.ts`, at most 25 in use, revoked never deleted, audited `integration.api_token_*`, `never` copied). A token acts as the owner who made it, whose membership is read again on every call (`apiCaller()`, `passMembership()`): a maker no longer an owner or a revoked token is a 401.
`/api/admin/v1/{resource}` with `Authorization: Bearer kf_…` (`routeOf()`, `src/lib/admin-api.ts`; `runApiRoute()`, `src/server/admin-api.ts`): products (list, one, create a draft through the AI manager's catalogue tools over `saveProduct()`, change a draft; a live product and publishing are refused as `gated`, the owner's in the admin; no pictures), stock (places, levels with what can be sold, adjust and set through `adjustStock()` with the new movement source `api`, a variant named by id or
SKU, a level that moved since the caller's `compare` a conflict, never overwritten), orders (list with `status` and `unfulfilled`, one with addresses, lines and what is left to send; a parcel with tracking through `markSent()` and the parcel's email through `sendShipped()` unless `notify` is false; copied orders read-only), customers (list, one with tags; tag and untag through `addTag()`/`removeTag()`) and discount codes (list, create through the admin form's `saveDiscount()`).
Lists are pages of at most 100 under an opaque cursor (`after`, `next`); money is minor units with the currency, in the order's or market's own; every change is audited `integration.api_{what}` with the token's name; 120 calls a minute per token (`takeBudget()`, `api`), a 429 with `Retry-After`; another store's ids are a 404; an out-of-scope call a 403 that names the scope.
The movement recorder's own list of sources (`record_inventory_movement()`) learns `api` and `exchange`, which it never had (an exchange's movements read `system` until now). Closes `platform.public-admin-api-and-custom-apps` and `orders.3pl-and-fulfilment-network`. Migration versions: `20261028093849_api_tokens` (applied by CI on 28 October 2026; advisors INFO only).
