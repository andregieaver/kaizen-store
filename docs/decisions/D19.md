# D19: Owners choose their own plan, and can own several stores

**Owners choose their own plan, and can own several stores.** On a store's Plan page the owner picks a plan (monthly or yearly, in the store's currency) and pays by card through Stripe Checkout; later changes apply at once with proration, and they can cancel at the end of the period. An owner can create more stores from All stores, each a copy of the demo with its own Stripe account and plan.

Date: 2026-09-24

Plans still belong to a store, not a person. Platform admins can still put a store on an invoiced plan (D18). Only people who already own a store, or run the platform, can create stores (up to 10 each), so the beta stays invite-only (P3). `stores` is a reserved store address.
