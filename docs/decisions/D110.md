# D110: A whole store can be translated with AI in one go, and a person reads every text before it is saved

**A whole store can be translated with AI in one go, and a person reads every text before it is saved.** *Translate the store* (`/admin/{store}/translate`, `StoreTranslator`, `src/lib/store-translate.ts`, `src/server/store-translate.ts`) takes a language the store offers (D109) and the scopes products, menus and pages/articles, finds what has no text in it yet (or everything again) from the store's main language (`translationWorklist()`: products' title, description, search title and description
from `product_translations`; a menu link's text when the owner wrote one in the main language, since a link without one is named by what it links to; the texts of each page's or article's draft, as the page builder's *Translate with AI* lists them), and shows how many there are (the first hundred per run; run again for the rest).
The texts go to the store's AI in batches through the page translation action (`translateStorePageAction`, feature `page_translation`): only words, never prices or stock, each answer checked for shape, length and the claims filter as in D109. What comes back is a review, not a write: each product, link or page with the main language beside the suggestion (plain texts editable), a tick to keep it, and nothing is written until *Save*.
Saving (`applyTranslations()`) checks each text again against the store's own text (only texts it asked for, in the shape and length their place allows, whatever the browser sent) and writes where the store's own editors write: `product_translations` (a translation needs a title, so texts without one are not kept), the menu's items with the label added and the rest of the item untouched, and a page through `savePage()` as a draft with its translation added, so pages are checked as always and
never published for staff; search by meaning follows through `refreshStoreEmbeddings()`. Legal texts are listed apart and start unticked, because a machine translation of them needs a person's review (docs/plan.md, D58): a product's safety information (a unit of its own) and pages whose address or title says terms, privacy, returns, withdrawal, cookies or imprint (`isLegalPage()`, in the languages the stores write in); an owner can still keep them once read.
Any member who edits products and pages can use it. Not yet: translating store SEO texts, business details and emails' own texts, translating variants' option names and pictures' alt texts in the same run (the media library does the latter), and a review that remembers a run between visits.

Date: 2026-09-29

Asked for by the owner after D109: translating products, menus and legal texts in one go. Suggest-then-read keeps the store answerable for what it publishes, and legal texts are the ones where a wrong translation costs most, so they are never ticked for the person. Writing pages as drafts uses the editor's own save, so nothing new can put a page in a state the editor would refuse.
