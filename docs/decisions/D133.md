# D133: Shipping carriers are prepared under Integrations

**Shipping carriers are prepared under Integrations** (`docs/shipping-carriers.md`, `src/lib/shipping-carriers.ts`, `src/server/shipping-carriers.ts`, `commerce.shipping_carriers`): Posten / Bring, PostNord, Porterbuddy and Helthjem are listed as cards with "Preparing" until their connections exist.
An owner saves the store's own agreement now (environment, customer number and API details, the markets to ship to); secrets are encrypted and shown only as their last four characters, and nothing is sent to any carrier.
The registry says what each will do and what it needs (the exact credential fields are confirmed against each carrier's API documentation when its connection is built), and `ShippingCarrierAdapter` is the one interface each connection will implement (check, rates, pickup points, booking with labels, tracking). Agreements are never copied to a duplicated store.
