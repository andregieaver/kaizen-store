# D659: A/B tests made plain, step 1

**A/B tests made plain, step 1: the test's page as a record (`docs/ab-testing-usability.md`, `docs/ab-testing.md` phase 12; 16 November 2026).** A pure `experimentCard()` (`src/lib/experiment-card.ts`) gives a started test its stage (still learning, has an answer, data problem, decided), the one next step, progress against the minimum days and visitors with the day both are likely reached, and each version's likely range at the verdict's own level, so the page and the verdict can no longer
disagree (they did: "No clear difference" above "96 % chance it is better"). The page is drawn in round 1's record pattern: the stage chip and one green button in the header (*Use Version B*, *Keep the original*, *Start now*; none while learning) with *More*, `StepPath`, progress bars, *How sure are we?*, *What is different* (`versionDifferences()`, `differenceLine()` shared with the versions dialogs), the trend with axes and the funnel as bars; every table behind *How we worked this out*.
Deciding stops a running test in the same press (`decideExperimentAction`). Nothing points a direction before the minimum, the early verdict sentence included. `explain_results` adds the stage, progress, ranges, what each version changed and the days (its description unchanged). Applying a whole-page winner keeps the page's own title (it took "… (B)").
