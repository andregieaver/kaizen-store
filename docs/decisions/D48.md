# D48: Rows, columns and components have settings of their own, in three tabs

**Rows, columns and components have settings of their own, in three tabs.** Each settings dialog has General, Style and Advanced. Every row, column and component gets an id and classes (Advanced), used on the site only: the editor leaves them out so a class cannot hide what is being edited. An id starts with a letter, is used once per page and is not one the site uses (`main`); a copy (duplicate, or a saved part put on the page) keeps its id only while the page does not use it.
Rows: width (the content's or the whole screen's) and, when full, the content's width; at least as tall as the screen; columns reversed on phones; equal column height; column content at the top, middle or bottom; a background colour or picture with an optional colour over it at an opacity. Columns: a background, and the whole column as a link (a safe address as for rich text, and an optional description for screen readers, else the column's text; links in its text still work).
Rich text: alignment left, centre or right on phones, from tablets (768 px) and from computers (1024 px), each following the smaller unless set. Pictures: original shape, or cropped to landscape (4:3), portrait (3:4), panorama (3:1), square or circle. The site and the canvas draw parts with the same code (`src/components/page-parts.tsx`); the site's `<main>` is full width and each row keeps to the content's width itself.

Date: 2026-09-25

Asked for by the owner. Settings are optional fields in the page's JSON (no migration), left out when off so unchanged pages compare equal. Classes only change the look where the site's styles define them; there is no custom CSS yet. Text keeps its colour over a background: a text colour setting would come separately.
