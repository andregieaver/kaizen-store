# D741: CI deploys a passed commit when the newer run it waited for fails

**CI deploys a passed commit when the newer run it waited for fails.** A run that leaves its deploy to a newer push (D710) now runs `scripts/deploy-fallback.mjs`: it waits while newer runs go on; when all have finished and `/api/health` still lacks its commit, it deploys that commit by sha through Vercel's API (secret `VERCEL_TOKEN`) and verifies it, or fails red saying why. (Run 1545 failed after 1544 deferred: hours, silently.) `docs/ci-migrations.md`.
