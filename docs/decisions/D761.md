# D761: Orders after a message by one rule

**Orders after a message by one rule (email plan M1.4).** `creditOrders()` (`src/lib/order-credit.ts`) gives each paid order to the latest broadcast, automation email or text that reached its buyer (address or account) in the 7 days before it; `orderCredit()` finds the pairs from all three at once. Automations, a broadcast's report (frozen with its figures at 90 days), a text's page and Analytics → Marketing use it. Idle cost: none; read only when those pages open.

Date: 2026-11-18
