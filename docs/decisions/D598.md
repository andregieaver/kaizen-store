# D598: A checkout question can be a tick list, with the EU's 14 allergens ready-made and an explicit consent for sensitive answers

**A checkout question can be a tick list, with the EU's 14 allergens ready-made and an explicit consent for sensitive answers (task 3 of `docs/checkout-fields-tasks.md`; 14 November 2026, `src/lib/checkout-presets.ts`).** A question of kind `checklist` has options (1 to 30, `checkout_fields.options`, each with words per language and an id kept with answers; one may be `none`, which clears the others) and counts as one question. *Use the EU's 14 allergens* fills it with Annex II of Regulation
(EU) No 1169/2011 in the store's languages (hand-written nb, sv, da, en) and None of these. `checkout_fields.sensitive` marks an answer that may be sensitive personal data (GDPR article 9, such as allergies): the cart then shows a consent box once an option other than none is ticked, and `cleanAnswers()` refuses the answer without it.
The order keeps the options ticked in the store's main words, their ids and the consent (`CheckoutAnswer` of kind `checklist`), read by the order page, the export and the person's export. A change without options or the consent flag keeps them (`saveCheckoutField()`), so the AI manager can reword a tick list but not make one. Admin API contract 1.17. Tests: `checkout-rules.test.ts`, `checkout-presets.test.ts`, `checkout-rules.int.test.ts`, `commerce.test.ts`.
