# D62: Sites' icons

**Sites' icons (favicons) are uploaded with the logos.** Stores and Kaizen upload an icon under Header and footer (`navigation.favicon`); the browser fits any picture (PNG, JPEG, WebP or SVG) into squares and uploads a 64 and a 512 pixel PNG (`squareIcon()`), so no icon format has to be made on the server.
Pages link them through `siteIcons()` in each root layout's metadata (the small for tabs, the large for home screens and Apple devices), and `/favicon.ico` redirects to the site's small icon, on a store's own host its own (`/s/{store}/favicon.ico`). Without one, Kaizen's icon (`public/kaizen/favicon.ico`, shared by every host) is shown.
