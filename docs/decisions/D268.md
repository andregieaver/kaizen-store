# D268: Two storefront fixes found while building Orbit

**Two storefront fixes found while building Orbit.** (1) A store theme that is always dark showed globals.css's default greys for its background, text, muted, surface and border colours, because `:root[data-color-mode="dark"]` out-weighed the theme's `html[data-store-theme]`; the theme is now drawn under `STORE_THEME_SELECTOR` (`html:root[data-store-theme]`, one part heavier), held by a test that weighs it against every globals.css rule that sets the colours.
The previews and the theme photographs scope the theme differently, so they never showed it; two launch theme presets are always dark. (2) A menu with a hover or active effect (D207) read the address with `usePathname()` outside a `<Suspense>` boundary, which stops a prerendered store page (any header using such a menu would have failed the build); its marker now streams inside a boundary whose fallback is the same still marker (`menu-view.test.ts`).

Date: 2026-10-16

Found on Far Light's own storefront. No migration.
