# D447: Moving from Wix

**Moving from Wix: the same three presses, built for the smallest shops (proposed 3 November 2026, `docs/moving-from-wix.md`; nothing built).** A Wix site is read through Kaizena Flow's own read-only Wix app on the move engine of D445, the reader asking Wix which catalogue the site runs (V1 or V3, never both) and reading that one; pages, which Wix's API does not give, are copied from the live site by the page replicator (D150) and approved by the owner on one screen; the address check also
covers `/product-page/` under any prefix, `/post/`, `/blank-…` and hash-bang addresses; move day is written for Wix's own DNS screen, never touching MX records. Wix's product and redirect files get readers first. Open for the owner: the email list (Wix's status carries no date as read, so a re-permission email by default), pages by replicator or by AI, members without orders, and Bookings later (section 13 of the plan).
