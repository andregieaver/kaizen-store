# deps: Dependencies

The dependency list is lean, and none of this dimension's case rests on what stores use today: 51 runtime packages, none without an importer, and every heavy browser library loads only on the press that needs it. The cost is in when server code loads: the page-view beacon takes about 1.0 s and 177 MB before its first answer where a lean route takes 0.22 s and 64 MB, and with three small import cuts (DP-10, DP-1, DP-3 step 1) its own code, bundled here, loads in 128-144 ms and 50 MB against 549-590 ms and 158 MB today. In the admin, Supabase's client and zod are 39% of the scripts a modern browser loads first on every screen (354 KB of 899 KB), the rich text editor (435 KB) is sent to 21 lists and detail pages, and every admin screen loads the AI manager's whole server side through two action files, a second door that the storefront review's cut does not close. Every P0 fix is a few lines in a few files, moves no data, and is cheapest now, before opening.
